고객 문의를 AI로 엑셀 정리하기: 분류부터 검산까지

고객 문의를 읽고 제품과 요청을 엑셀 칸마다 옮겨 적는 일부터 연습해보자. 클로드에 문의 열 건을 표로 나누게 한 뒤, 빠진 문의와 잘못 분류한 행을 원문으로 검사한다. 목표는 문의에 자동 답장하는 것이 아니라, 사람이 처리할 내용을 빠짐없이 정리하는 것이다.

확인 범위: 원영상의 실제 시연과 공식 이용 조건을 확인해 만든 따라 하기 안내다. 직접 확인한 Excel에는 Claude 추가 기능이 있었지만, 시작 오류와 로그인 화면이 나타나 문의 자료를 보내는 단계까지 진행하지 못했다. 아래 가상 문의의 자체 실행 검증은 미완료다. 따라서 이 글의 표는 실제 AI 출력이 아니라, 직접 실행한 뒤 비교할 검사 기준이다.

긴 문장에서 필요한 항목만 나누기

“노트 A를 받았는데 표지가 찢어져 있습니다. 환불 말고 같은 제품으로 교환하고 싶어요.” 이 한 문장을 제품, 요청 내용, 문의 구분으로 나누면 이후에 담당자가 읽기 쉽다. 여기서 ‘환불’이라는 단어만 보고 환불 문의로 분류하면 틀린다. 고객이 원하지 않는 처리까지 함께 읽어야 한다.

오빠두엑셀의 10분 24초 이후 시연에서는 A열의 긴 문의를 클로드로 항목별 표로 정리한다. 10분 58초에 입력 자료와 요청창, 11분 23초에 채워진 표가 나온다. 아래의 열 건은 그 강의의 고객 자료를 복제한 것이 아니라 별도로 만든 가상 연습 자료다. 검사 기준도 이 원문에 맞춰 작성했다.

Google Pro와 Claude Pro는 다른 구독

이 수업은 Claude for Excel을 사용한다. 구글 AI Pro를 구독했다고 이 기능까지 포함되는 것은 아니다. 클로드 공식 문서는 Pro·Max·Team·Enterprise 계정을 지원한다고 안내한다. 사용량은 기존 클로드 계정의 한도와 함께 적용된다.

Windows에서는 지원 버전의 Microsoft 365용 Excel이 필요하다. Excel 웹도 지원하지만 회사 계정은 추가기능 설치를 관리자가 제한할 수 있다. Excel 2016·2019 영구 버전과 태블릿용 앱을 같은 조건으로 소개하면 안 된다. 이용 가능한 계정과 Excel이 이미 있을 때 진행하고, 결제나 상위 요금제 전환 화면이 나오면 이번 연습은 멈춘다.

공식 설치 경로의 추가기능 이름은 ‘Claude for Microsoft 365’다. 설치가 허용된 환경에서는 Microsoft AppSource의 공식 목록에서 추가한 뒤 Excel의 홈 → 추가 기능에서 열고 클로드 계정으로 로그인한다. 회사에서 막아둔 설정을 우회하거나 모든 변경을 자동 승인하는 설정을 켜지 않는다. 아래 실습은 지정한 사본의 셀만 고치도록 범위를 좁힌다.

원본 두 열을 남기고 빈 결과 칸 만들기

가상 고객 문의 CSV를 내려받는다. CSV는 표의 각 칸을 쉼표로 구분한 텍스트 파일이다. Excel에서 바로 열었는데 한글이 깨지거나 한 열에 몰리면 데이터 → 텍스트/CSV에서로 가져와 UTF-8과 쉼표 구분을 확인한다. 처음 두 열은 ‘접수ID’와 ‘문의원문’이어야 한다.

파일을 다른 이름의 .xlsx 사본으로 저장하고 시트 이름을 ‘문의연습’으로 정한다. 원문은 A1:B11에 둔다. 제목 한 행과 문의 열 건이다. C1:H1에는 아래 여섯 제목을 차례로 적고, C2:H11은 비워둔다.

결과를 받을 여섯 열
C열D열E열F열G열H열
접수ID제품요청 내용문의 구분확인할 정보원문 근거

접수ID를 결과에도 남기는 이유가 있다. 같은 문장으로 접수된 문의가 두 개 있어도 서로 다른 접수 건일 수 있다. 이번 자료의 Q001과 Q009가 바로 그런 예다. 문장이 같다고 지워버리면 고객 한 명의 문의가 사라진다. 원본을 왼쪽에 그대로 두면 나중에 어느 행이 빠졌는지 찾기도 쉽다.

클로드에게 읽을 칸과 쓸 칸 지정하기

Excel 안의 클로드 입력창에 아래 문장을 붙여 넣는다. A1:B11은 읽을 원본 범위이고 C2:H11은 결과를 쓸 범위다. 다른 시트에 매출이나 직원 정보가 들어 있을 수 있으므로 ‘전체 파일을 알아서 정리해줘’라고 넓게 맡기지 않는다.

문의연습 시트 A1:B11만 읽고 C2:H11만 채워 주세요.
A1:B11 원문과 C1:H1 제목은 수정하지 마세요.

접수ID마다 한 행을 만들고 원래 순서를 유지하세요.
결과는 10행입니다. 문장이 같아도 ID가 다르면 합치거나 삭제하지 마세요.

제품, 요청 내용, 문의 구분, 확인할 정보, 짧은 원문 근거를 정리하세요.
문의 구분은 배송조회 / 교환 / 주문취소 / 제품정보 /
수리·사용법 / 확인필요 / 복합문의 중 고르세요.

교환과 환불을 혼동하지 마세요.
제품명이나 요청이 불명확하면 추측하지 말고 확인할 정보에 적으세요.
한 접수의 여러 요청은 같은 행에 모두 적고 복합문의로 표시하세요.

고객에게 답장하거나 외부 자료를 찾지 마세요.
다른 시트·파일·계정은 사용하거나 변경하지 마세요.
지정한 셀 밖의 변경이 필요하면 멈추고 이유만 알려주세요.

변경 승인 화면이 나타나면 바꿀 범위를 읽는다. 지정한 결과 칸 밖을 지우거나 다른 시트를 수정하는 계획이면 승인하지 않는다. 실행 후에는 AI가 ‘완료했습니다’라고 말했는지만 보지 말고, 실제 C2:H11에 값이 들어갔는지 확인한다. 여기까지가 표를 만드는 단계이고, 이제부터가 업무에 쓸 수 있는지 검사하는 단계다.

열 건이 열 행으로 남았는지 먼저 확인

가장 먼저 접수ID 열을 읽는다. Q001부터 Q010까지 한 번씩, 원래 순서대로 있어야 한다. 원본 열 건이 결과 아홉 행으로 줄었다면 문장이 같은 Q001과 Q009를 합치지 않았는지 살펴본다. 반대로 Q008의 복합 요청을 두 행으로 늘렸다면 이번에 정한 ‘접수 한 건당 한 행’ 기준과 맞지 않는다.

그다음 아래 다섯 군데를 본다. 이는 가상 원자료에서 사람이 만든 검사 기준이다. 실제 클로드가 이대로 출력했다는 성공 화면을 대신하지 않는다.

뜻이 바뀌기 쉬운 문의 대조표
접수남아 있어야 하는 뜻잘못된 정리
Q001·Q009각각 보존 · 같은 제품으로 교환 희망한 행으로 합침 · 환불로 분류
Q005제품과 교환·환불 여부 모두 확인 필요환불이 확정된 것으로 정리
Q006제품명 확인 필요 · 해결 방법 요청다른 행의 제품명을 가져옴
Q007펜 B를 주문했는데 파일 C를 받아 교환 요청주문 제품과 받은 제품을 뒤바꿈
Q008노트 A 환불과 펜 B 배송조회 둘 다 보존두 요청 가운데 하나만 남김

확인표에 없는 행도 원문을 한 번씩 읽는다. Q003은 취소 가능 여부를 물었으므로 ‘취소 완료’로 쓰면 안 된다. Q004는 A5 규격인지 묻지만 실제 규격은 자료에 없다. 제품 정보를 찾아 답하는 수업이 아니므로 ‘규격 확인 요청’으로 정리한다. Q010은 환불을 원하지 않고 수리 절차를 묻는다.

이 작업에서 AI에게 맡긴 것은 분류다. 환불 가능 여부, 택배 도착일, 제품 규격까지 답하도록 맡긴 것은 아니다. 제품명이나 날짜가 그럴듯해 보여도 원문에 없으면 확인할 정보로 돌려놓는다. 처음 열 건을 검사하는 동안에는 속도보다 누락과 뜻의 변화를 찾는 데 집중한다.

한 행만 고친 뒤 원본 보존까지 점검

예를 들어 Q008에서 펜 B 배송조회가 빠졌다면 아래처럼 해당 접수와 근거를 지정한다. 실제 결과에 그 오류가 있을 때만 사용한다. 잘된 행까지 다시 만들게 하면 어느 부분이 바뀌었는지 확인할 일이 늘어난다.

Q008 결과를 원문 B9와 다시 비교하세요.
원문에는 노트 A 환불과 펜 B 배송조회 요청이 모두 있습니다.
Q008의 결과 행 C9:H9에 두 요청을 모두 보존하고 복합문의로 표시하세요.
접수ID, 다른 결과 행, A1:B11 원문은 바꾸지 마세요.

수정 후 Q008의 두 요청을 다시 읽고, Q001과 Q009가 여전히 따로 있는지도 확인한다. 마지막에는 A1:B11 원문과 제목 행이 바뀌지 않았는지 사본을 원본과 비교한다. 이 검사가 끝난 파일만 따로 저장한다. 고객 답장과 외부 전달은 별도 판단이 필요한 다음 업무로 남긴다.

내 업무에 맞게 바꿀 부분

다음 연습에서는 문의 구분만 자기 업무에 맞게 바꿔볼 수 있다. 예를 들어 행사 담당자라면 참가 신청, 일정, 장소, 취소 문의처럼 나눈다. 그때도 원문 보존, 접수ID 유지, 정보가 없으면 확인 필요라는 세 조건은 그대로 둔다. 실제 개인정보를 넣기 전에는 회사에서 허용한 도구와 자료 범위를 확인한다.

엑셀을 처음부터 자동으로 완성하는 것보다, 짧은 원문 열 건을 바르게 옮기는 경험이 먼저다. 이 순서가 익숙해지면 더 많은 문의를 정리할 때도 무엇을 맡기고 무엇을 사람이 검사할지 설명할 수 있다. 좋은 결과는 칸이 가득 찬 표가 아니라 원문 열 건의 뜻이 빠짐없이 남아 있는 표다.
