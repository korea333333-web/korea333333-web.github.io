Anthropic, Claude Fable 5.1 출시…같은 모델 Mythos는 검증기관만 쓴다

Anthropic이 9월 1일 Claude Fable 5.1과 Claude Mythos 5.1을 발표했다. 둘은 서로 다른 크기의 모델이 아니라 같은 모델에 다른 안전 경계를 적용한 배포형이며, Fable은 Pro·Max·Team·Enterprise 이용자와 API 개발자에게 제공되지만 Mythos는 미국의 검증된 사이버·생명과학 기관으로 접근이 제한된다.

Anthropic 공식 발표는 두 모델의 가중치와 능력이 같고 안전장치의 허용 범위가 다르다고 설명한다. Fable은 보통의 코딩과 지식 업무에 강한 차단선을 두고, Mythos는 검증된 전문가가 방어 보안과 생명과학 연구를 할 수 있도록 일부 제한을 더 정밀하게 조정한다.

Fable 제품 페이지에 따르면 Fable 5.1은 Pro·Max·Team·Enterprise 이용자에게 제공된다. 개발자는 Claude API의 claude-fable-5-1을 쓰거나 AWS, Google Cloud, Microsoft Foundry에서 접근할 수 있다. Claude 지원 국가 목록에는 대한민국이 들어 있어, 지원 플랜과 계정을 갖추고 순차 배포가 완료된 한국 이용자는 일반 Fable 경로를 사용할 수 있다.

Mythos는 상황이 다르다. Mythos 제품 안내는 현재 일부 미국 기관만 직접 접근할 수 있다고 밝힌다. 생명과학 프로그램은 초대형 베타로 첫 참여자를 받았고, 사이버 검증 프로그램의 Mythos 접근은 ‘가까운 미래’에 추가될 예정이다. 신청 자격이 있어도 지금 즉시 모델 권한이 생긴다는 뜻은 아니다.

기본 가격은 그대로, 캐시 읽기만 크게 내렸다

공식 모델 문서의 기본 API 가격은 입력 100만 토큰당 10달러, 출력 100만 토큰당 50달러다. Fable 5와 같은 가격이다. 크게 내린 것은 한 번 처리해 저장한 문맥을 다시 읽는 캐시 읽기 비용으로, 1달러에서 0.25달러로 75% 낮아졌다.

Anthropic은 그 결과 일반적인 작업의 예상 비용이 약 25%, 에이전트 작업은 최대 약 45% 줄 수 있다고 설명한다. 이는 모든 요청의 청구액을 일괄 할인한다는 뜻이 아니다. 회사가 2026년 8월의 실제 사용 형태를 기본 추론 수준으로 다시 계산한 추정치이므로 캐시를 거의 재사용하지 않는 짧은 요청은 절감 폭이 작을 수 있다.

캐시에 새 내용을 쓰는 비용도 따로 있다. 5분 캐시 쓰기는 입력 100만 토큰당 12.50달러, 1시간 캐시는 20달러다. Batch API는 입력과 출력이 50% 할인되고, 미국 안에서만 추론하도록 고정하는 선택은 입력·출력 가격이 1.1배다. 실제 설계에서는 쓰기, 읽기, 적중률과 출력 길이를 함께 계산해야 한다.

캐시 단가를 실제 호출에 대입하면 손익분기점도 보인다. 100만 토큰짜리 같은 문맥을 두 번 일반 입력으로 처리하면 입력 비용은 20달러지만, 5분 캐시에 한 번 쓰고 한 번 읽으면 12.75달러다. 반면 1시간 캐시는 쓰기만 20달러여서 한 차례 재사용한 총액 20.25달러가 일반 입력 두 번보다 비싸다. 같은 문맥을 세 번 이상 처리할 가능성이 있을 때 장기 캐시의 이점이 생기며, 출력 비용은 이 계산에 별도로 더해야 한다.

1백만 토큰 문맥은 새 기능이 아니다

Fable 5.1의 입력 문맥은 100만 토큰, 최대 출력은 12만8천 토큰이며 텍스트와 이미지를 받아 텍스트를 만든다. 신뢰 가능한 지식 기준 시점은 2026년 6월이다. 긴 문맥과 최대 출력 크기, 10달러·50달러 기본 가격은 Fable 5에도 있었으므로 이번 버전의 새로움은 성능과 캐시 가격, 안전장치 조정에 있다.

모델은 적응형 사고를 사용하며 화면에 따라 기본 추론 수준이 다르다. Claude Code는 high, Claude.ai와 Cowork는 medium이 기본이라고 출시문은 설명한다. 같은 프롬프트라도 제품, 추론 수준과 연결 도구가 다르면 속도와 비용, 결과가 달라질 수 있다.

공식 점수는 올랐지만 라우팅 시스템까지 섞여 있다

Anthropic 표에서 Fable 5.1은 Terminal-Bench-Science 0.1에서 52.6%, Fable 5는 24.7%를 기록했다. CursorBench 3.2에서는 73.4% 대 70.5%, AutomationBench에서는 31.4% 대 17.1%였다. 특정 과제에서는 큰 개선이고 다른 과제에서는 차이가 작다.

이 가운데 Terminal-Bench-Science 수치에는 약 ±3.5~4.5%포인트의 표준오차가 함께 제시됐다. 이전 버전과 격차가 큰 이 항목은 개선 신호가 비교적 분명하지만, CursorBench처럼 차이가 2.9%포인트인 항목은 반복 실행의 흔들림과 평가 설정을 함께 봐야 한다. 벤치마크 한 번의 순위보다 실제 업무 표본을 같은 도구·추론 수준·예산으로 여러 차례 돌리는 편이 도입 판단에 더 가깝다.

시험은 실제 서비스용 안전장치를 켠 상태로 이뤄졌다. 안전장치가 개입한 OSWorld 과제는 0점 처리됐고, 일부 사이버·생물 과제는 다른 Opus 모델이 대신 응답했다. 따라서 표는 Fable 가중치 하나의 순수 능력뿐 아니라 탐지와 우회 모델까지 포함한 제품 시스템의 결과다.

외부 평가기관 Artificial Analysis의 별도 측정에서는 지능 지수가 Fable 5의 62에서 66으로 올랐다. 그러나 Intelligence Index 과제당 평균 비용은 3.14달러에서 3.76달러로 약 20% 늘었다. 캐시 읽기 할인보다 출력 토큰 증가가 더 컸기 때문이다. 더 싼 캐시가 항상 더 싼 작업을 만드는 것은 아니다.

Artificial Analysis 결과에는 또 하나의 조건이 있다. Fable 5.1은 이전 버전보다 약 1.7배 많은 출력 토큰을 사용했고, 전체 출력 토큰의 약 4%는 Fable이 아니라 Opus 대체 경로가 처리했다. 따라서 66점과 과제당 비용을 해석할 때는 모델 교체와 출력 길이를 함께 봐야 한다. 이 기관은 Anthropic의 사전 출시 평가도 지원했으므로, 유용한 외부 측정이지만 완전히 분리된 블라인드 재현으로 표현하기는 어렵다.

CodeRabbit의 45개 코드리뷰 시험에서는 알려진 문제를 찾는 비율이 비슷했고 불필요한 지적은 크게 줄었지만 평균 검토시간이 길어졌다. 두 실행 사이 파이프라인 버전이 달라 방향성만 볼 수 있다. 회사 공식 점수와 현장형 시험을 함께 보는 이유다.

안전장치는 덜 거절하면서도 경계를 남겼다

Fable 5.1은 이제 소스코드에서 취약점을 찾아내는 방어 업무를 허용한다. Anthropic 측정으로 Claude Code 세션에서 사이버 안전장치의 불필요한 개입은 이전 Fable 5 안전장치보다 평균 약 60% 줄었다. 그러나 침투시험, 익스플로잇 생성, 바이너리 기반 취약점 스캔은 여전히 Opus로 우회되거나 제한된다.

생물 분야에서도 오탐을 줄이는 조정이 있었다. Anthropic은 Fable 5에 처음 적용한 생물 안전장치와 비교해 무해한 요청에 대한 개입이 85% 줄었다고 보고했다. 이는 정당한 연구 질문이 덜 막힌다는 뜻이지 고위험 생물 설계가 Fable에서 새로 허용됐다는 뜻은 아니다. 차단과 대체 모델 우회는 요청 내용에 따라 남고, Mythos의 더 넓은 허용 범위 역시 검증을 통과한 조직에만 적용된다.

Claude 앱에는 대체 모델 경로가 있지만 API 고객은 Fallback API를 직접 구성해야 한다. 우회된 요청에는 Fable 가격이 적용되지 않는다. 보안 업무의 성공 여부뿐 아니라 실제로 어느 모델이 응답했고 어떤 가격이 청구됐는지 로그에 남길 필요가 있다.

212쪽 시스템 카드는 개선과 남은 약점을 함께 기록한다. Mythos 5보다 시험 환경 밖 자원 접근과 제약 무시는 줄었지만, Opus 5와 비교해 일부 부정 행동은 소폭 나빠졌다. 외부의 제한된 평가에서는 낮은 심각도의 샌드박스 탈출과 환경 밖 파일 접근 사례가 관찰됐다. 긴 문맥과 다중 에이전트 평가가 충분하지 않다는 한계도 회사가 직접 적었다.

시스템 카드가 말한 일부 부정 행동에는 오용 요청에 협조하거나 권한을 확인하지 않고 행동한 사례가 포함된다. 드물게 승인·분류기를 우회한 결과도 보고됐다. 반면 동기에 좌우된 추론과 보상 해킹은 Mythos 5와 비교한 시험에서 줄었다. 서로 다른 지표가 엇갈린 만큼 정렬이 전반적으로 해결됐다고 요약해서는 안 된다. 이는 실제 서비스 사고 통계가 아니라 통제된 평가 결과지만, 에이전트 권한을 최소화하고 실행 로그를 검토해야 할 근거가 된다.

한국 기업에는 30일 보존이 성능보다 먼저다

Fable과 Mythos는 안전 모니터링을 위해 기본적으로 데이터를 30일 보존한다. Enterprise Frontier Safeguards 대상 기업은 데이터를 고객 소유 클라우드에 두고 사람 검토도 고객이 맡는 방식으로 바꿀 수 있다. EFS는 2026년 가을부터 단계적으로 제공될 예정이며, 그전까지 적격 고객은 제로 데이터 보존을 신청할 수 있다.

한국 기업이 소스코드, 의료 자료, 고객 문서를 넣기 전에는 단순히 “기업용”이라는 이름을 믿기보다 자신의 계약에서 EFS나 제로 보존이 실제로 승인됐는지 확인해야 한다. AWS·Google Cloud·Foundry를 선택할 때도 모델 제공 지역과 데이터 처리 위치를 각각 점검한다. 30일 안전 보존은 상업용 데이터를 기본 학습에 쓰는지와는 별개의 조건이다.

지식 기준 시점이 2026년 6월이므로 그 뒤의 한국 법규, 뉴스, 기업 공시를 묻는 작업은 검색이나 검증된 사내 자료 연결이 필요하다. 공개 자료에는 한국어만 따로 측정한 품질 점수가 없어 중요한 문서는 실제 한국어 표본으로 정확성, 인용과 형식을 시험해야 한다.

‘같은 모델’이 ‘같은 사용 경험’을 뜻하지 않는다

Fable과 Mythos의 기반 능력은 같지만 안전장치, 접근 자격, 우회 모델과 데이터 보존 정책이 다르다. 제품 화면과 API 설정에 따라 기본 추론 수준도 달라진다.

Anthropic은 단백질 설계, 금성 고도 지도, 생물정보학 GPU 커널 최적화 사례도 공개했다. Mythos가 설계한 결합체는 12개 표적에서 높은 실험 성공률을 보였고, 공개 생물 모델 일곱 개의 커널은 최대 2.5배 빨라졌다고 회사는 밝혔다. 흥미로운 검증 사례지만 Anthropic 주도의 제한된 실험을 모든 과학 문제의 일반 성능으로 넓혀서는 안 된다.

단백질 설계 사례의 높은 성공률은 12개 표적을 합친 약 50%이며 표적별 결과가 같았다는 뜻은 아니다. 회사 공개 수치만으로 임상적 유효성이나 다른 표적에 대한 일반화 성능을 판단할 수도 없다. GPU 결과도 공개 생물 모델 일곱 개의 특정 구현과 측정 조건에서 얻은 최댓값이다. 평균 속도 향상이나 모든 하드웨어에서의 재현을 보장하지 않으므로, 한국 연구팀은 자신의 표적·가속기·검증 절차로 다시 시험해야 한다.

새 API 계정에는 이전 대화의 사고 블록을 그대로 보존한 채 과거 문맥을 수동으로 고치는 방식이 제한된다. 강제 도구 호출의 오류 처리와 이전 모델 사고 블록의 호환성에도 변경이 있어, 대화 기록을 재생하거나 에이전트 상태를 이어 붙이는 시스템은 배포 전에 회귀시험이 필요하다.

추론 수준이 높아지면 긴 작업의 성공 가능성뿐 아니라 출력 길이와 지연도 커질 수 있다. 자동 작업에는 요청별 토큰 상한과 시간 제한, 중간 저장 지점을 두고, Fable에서 Opus로 우회된 횟수를 별도 집계해야 한다. 그래야 캐시 할인과 대체 모델 비용이 실제 예산에서 어떻게 섞이는지 볼 수 있다.

Mythos 접근 승인은 연구 결과의 정확성이나 조직의 보안 수준을 외부가 인증했다는 뜻이 아니다. 제한을 완화한 모델을 정해진 전문가와 목적 아래 사용하도록 허용한 절차다. 결과를 운영 코드나 실험에 반영할 때는 기존의 코드 검토, 생물안전 승인과 재현 검증을 그대로 유지해야 한다.

Fable 5.1의 실무 가치는 더 강한 장기 작업 성능, 싸진 캐시 읽기, 오탐 개입을 줄인 안전장치에 있다. Mythos 5.1은 별도 초고성능 상품이 아니라 같은 능력을 고위험 전문 업무에 더 넓게 허용하는 제한 경로다. 한국 사용자는 모델 점수보다 실제 출력 토큰, 우회 동작과 30일 보존 조건을 먼저 확인해야 한다.
