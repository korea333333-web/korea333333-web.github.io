클로드 코드, 금지한 파일을 읽던 문제와 사라지던 대화를 고쳤다

앤트로픽이 클로드 코드에서 금지한 파일을 읽을 수 있던 문제와 대화 기록 오류를 고쳤다. 수정 버전은 v2.1.290·v2.1.291이다.

클로드 코드는 AI가 컴퓨터의 파일을 읽고 고치며 프로그램을 만드는 도구다. 이용자는 읽을 수 있는 폴더와 사람에게 물어봐야 할 행동을 정할 수 있다.

컴퓨터에는 다른 파일의 위치를 가리키는 연결이 있다. 기술 문서에서는 ‘심볼릭 링크’라고 부른다. 예를 들어 ‘참고 자료’라는 이름을 눌렀는데 다른 폴더의 문서가 열리는 식이다. 공식 권한 설명은 요청한 파일 이름과 연결 끝의 실제 파일을 모두 검사한다고 안내한다. 허용 규칙은 두 경로가 모두 맞아야 적용되고, 금지 규칙은 어느 한 경로라도 해당하면 적용된다.

파일 연결이 바뀌던 허점

v2.1.290은 맥·윈도에서 이미지를 읽는 중 연결이 바뀌어 승인 밖 파일을 읽던 허점을 고쳤다. 작업 폴더 밖 읽기를 막았거나, 파일 읽기를 제한한 모드에서 파일을 대화에 직접 언급할 때도 같은 문제가 있었다.

이미지를 붙이거나 끌어 넣을 때 읽기 금지 규칙이 빠지던 부분도 보완했다. 폴더를 대화에 언급할 때 금지한 파일 이름이 나오던 문제도 고쳤다.

개인 기능보다 회사 규칙을 지킨다

개인 확장 기능이 회사의 확장 기능이나 안전 검사를 꺼 버리거나 건너뛰던 문제도 수정했다. 확장 기능은 별도 기능을 더하는 프로그램이다. 충돌하는 개인 기능을 내려 회사 규칙을 유지한다.

290에서 생긴 승인 답변 오류도 291에서 고쳤다

뒤이어 나온 v2.1.291의 수정 항목은 두 가지다. 하나는 v2.1.290의 클라우드 작업에서 권한 요청에 대한 답변이 누락될 수 있던 오류다. 다른 하나는 v2.1.288에서 생긴, 프로그램을 종료할 때 대화의 마지막 메시지를 잃을 수 있던 오류다.

클라우드 작업은 회사 서버에서 AI가 일을 처리하는 방식이다. AI가 작업 승인을 기다리는데 이용자의 답변이 전달되지 않으면 일이 진행되지 않거나 같은 질문에서 막힐 수 있다. 승인 창을 제대로 만드는 것뿐 아니라, 사람이 보낸 답변을 끝까지 전달하는 일도 필요하다.

마지막 메시지가 사라지면 종료 직전에 남긴 수정 요구를 다음에 찾지 못할 수 있다. v2.1.291은 종료할 때의 유실을 고친다. 이미 잃은 메시지의 복구 방법은 발표하지 않았다.

사용 중인 버전부터 확인하면 된다

개발자를 위한 확인 방법은 간단하다. 명령을 입력하는 창인 터미널에서 claude --version을 입력하면 설치 버전이 나온다. 공식 설치·업데이트 안내는 지원되는 설치 방식에서 claude update로 수동 업데이트하는 방법을 제공한다. 회사가 설치 버전을 관리하거나 다른 설치 도구를 썼다면 해당 관리 방식으로 업데이트한다.

자료와 그림 안내

한국 시간으로 v2.1.290은 10월 6일 오전 8시 33분에 공개됐다.

v2.1.291은 같은 날 낮 12시 55분에 공개됐다. 대표 그림은 이 글을 위해 만든 AI 콘셉트 이미지다.

  • 클로드 코드 v2.1.290 변경 기록
  • 클로드 코드 v2.1.291 변경 기록
  • 공식 파일 접근·권한 규칙 설명
  • 공식 버전 확인·업데이트 안내

대표 그림은 AI로 직접 만든 설명 그림이다. 한국어 문구는 그림과 분리해 배치했다. 본문 도식·그래프는 연결한 원문에 근거해 직접 제작했다.
