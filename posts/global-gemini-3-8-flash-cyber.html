구글, Gemini 3.8 Flash 정식 출시…Cyber는 심사 통과 파트너만 쓴다

구글이 9월 2일 Gemini 3.8 Flash를 정식 출시하고, 같은 계열의 방어 보안용 Gemini 3.8 Flash Cyber를 공개했다. 일반 모델은 한국에서도 API와 여러 구글 제품을 통해 쓸 수 있지만 Cyber는 Fairwind 심사를 통과한 신뢰 파트너에게만 제한 제공된다.

구글 공식 발표와 Gemini API 변경 기록은 gemini-3.8-flash를 GA, 즉 정식 제공 모델로 표시한다. 미리보기 단계가 아니다. 개발자는 Gemini API와 AI Studio, Antigravity, Android Studio, Stitch에서 접근할 수 있고, Gemini Enterprise와 Pro·Ultra 이용자의 Gemini 앱·AI Mode·Sheets에도 제공된다.

공식 모델 문서에 따르면 입력은 텍스트·이미지·음성·영상·PDF를 받고 출력은 텍스트다. 입력 문맥은 104만8,576토큰, 최대 출력은 6만5,536토큰이다. 함수 호출, 검색 근거 연결, 코드 실행과 구조화 출력은 지원하지만 실시간 Live API, 음성·이미지 생성과 모델 튜닝은 지원 목록에 없다.

구글은 이를 6주 안에 내놓은 세 번째 Flash 업데이트이자 자사 최고 수준의 추론·코딩 Flash라고 설명한다. 다만 제품 이름의 ‘Flash’는 모든 작업이 더 빨리 끝난다는 보증이 아니다. 초당 생성 속도, 첫 응답 대기시간, 모델이 사용하는 토큰과 전체 에이전트 작업시간은 서로 다른 지표다.

싼 도입가는 올해 말까지만 적용된다

Gemini API 가격표의 표준 유료 가격은 입력 100만 토큰당 0.75달러, 출력 100만 토큰당 3.75달러다. 출력 가격에는 내부 사고 토큰이 포함된다. 중요한 조건은 이 가격이 2026년 12월 31일까지인 도입가라는 점이다.

2027년 1월 1일부터 표준 가격은 입력 1.50달러, 출력 7.50달러로 각각 두 배가 된다. Batch·Flex와 Priority 가격도 같은 날 두 배로 바뀐다. 캐시와 검색 근거 연결에는 별도 비용이 붙을 수 있고, 일부 비글로벌 Cloud 엔드포인트에는 지역 가산이 적용된다.

표준 요금만으로는 에이전트의 실제 원가를 계산하기 어렵다. 2026년 말까지 Batch와 Flex는 입력 100만 토큰당 0.375달러, 출력 1.875달러이고, 지연보다 우선 처리가 중요한 Priority는 1.35달러와 6.75달러다. 2027년 1월부터 이 단가들도 각각 두 배가 된다. 같은 모델이라도 즉시성, 처리량, 재시도 방식에 따라 청구 경로가 달라지므로 요청 수와 완료 시간까지 함께 기록해야 한다.

캐시와 검색도 별도 원가다. 컨텍스트 캐시는 2026년 말까지 100만 토큰당 0.075달러에 저장 시간당 0.50달러가 붙고, 다음 해에는 0.15달러와 1달러가 된다. Google Search 근거 연결은 Gemini 3 계열이 한 계정의 월 5,000회 무료 검색 요청을 나눠 쓰고, 이후 1,000회당 14달러다. 한 사용자 요청이 여러 검색 질의를 만들면 생성된 질의마다 계산될 수 있어, 조사형 에이전트는 토큰 단가만 비교해서는 비용을 예측하기 어렵다.

기존 3.7 연동 코드는 모델 이름만 바꾸기 전에 요청 옵션을 점검해야 한다. 공식 기업용 가이드는 3.8의 추론 수준을 low·medium·high로 나누고 기본값을 medium으로 둔다. minimal은 오류를 내며, 예전의 temperature·top_p·top_k는 더 이상 동작을 조절하지 않고 무시된다. candidate_count와 frequency·presence penalty도 지원하지 않는다. 응답 형식과 함수 대화 규칙도 더 엄격해졌으므로, 성공 응답뿐 아니라 무시된 옵션과 잘못된 함수 순서가 운영 로그에 남는지 확인할 필요가 있다.

104만 토큰 문맥창은 최신 지식이나 전 구간의 동일한 정확도를 뜻하지 않는다. 모델 카드는 일부 영역의 지식 기준일을 2026년 3월로 적지만, 분야에 따라 2025년 1월 수준에 머무를 수 있다고 경고한다. 검색 근거 연결은 최신 자료를 보완할 수 있어도 출처가 틀리거나 질문과 어긋날 가능성까지 없애지는 않는다. 긴 계약서와 저장소를 넣을 때는 중간과 끝의 핵심 조건을 따로 묻고, 인용 위치와 함수 결과를 원문에서 다시 확인해야 한다.

무료 티어 표시도 소비자용 Gemini 앱을 누구나 무료로 쓴다는 뜻은 아니다. API 무료 사용의 한도와 데이터 처리 조건은 유료 요청과 다르다. 공식 가격표는 무료 티어의 콘텐츠가 제품 개선에 사용될 수 있고 유료 콘텐츠는 그 용도로 사용하지 않는다고 구분한다.

성능은 올랐지만 ‘모든 벤치 1위’는 아니다

구글 표에서 3.8 Flash는 금융 에이전트, 코딩, 지식 추론 등 여러 항목에서 3.7보다 개선됐다. HLE-Verified는 구글 측정 54.9로 GPT-5.6 Sol 54.5, Claude Opus 5 54.4보다 0.4~0.5%포인트 높다. 반면 공식 Cloud 표의 원본 HLE에서는 3.8이 45.4, 3.7이 45.7이었다. 평가판과 작은 차이를 구분해야 한다.

평가 방법 문서를 보면 Gemini 결과는 구글 자체 실행값이 많고 경쟁 모델 값은 공급자 보고와 공개 순위표가 섞여 있다. 작업에 따라 프레임 수와 도구, 추론 설정, 여러 번 실행한 값의 선택 방식도 다르다. 표는 유용한 출발점이지만 동일 조건의 완전한 독립 대결표는 아니다.

독립 DeepSWE 순위표에서는 같은 mini-swe 에이전트로 3.8 Flash high가 74%를 기록했다. Claude Opus 5도 74%, GPT-5.6 Sol은 73%로 오차범위가 겹친다. 3.8은 최상위권이지만 단독 우승이라고 말할 수 없는 결과다.

Artificial Analysis의 독립 분석은 약 초당 300개 출력 토큰과 높은 가격 대비 성능을 장점으로 꼽았다. 동시에 한 작업이 쓰는 평균 출력 토큰과 비용은 3.7보다 늘었고 전체 작업시간도 약간 길었다. 빠른 생성 속도와 더 싼 작업비는 항상 함께 움직이지 않는다.

모델 카드는 환각이 계속 발생할 수 있고, 높은 추론 수준에서는 토큰 사용량과 지연이 늘며, 간헐적인 느림과 시간 초과가 남아 있다고 적는다. 일부 자동 안전평가에서는 3.7보다 다국어 위반과 불필요한 거절 지표가 나빠졌다. 실제 한국어 업무 표본을 따로 시험해야 하는 이유다.

Flash Cyber는 공개 API가 아니라 승인형 경로다

Flash Cyber는 정부·국가 사이버기관, 의료·통신·에너지·금융 같은 핵심 인프라, 핵심 기술 플랫폼과 오픈소스 유지관리자를 우선 대상으로 한다. 신청자는 Fairwind 프로그램의 심사를 거쳐야 하며, 승인되면 독립형 또는 CodeMender와 연결된 형태로 쓸 수 있다.

허용 범위에는 승인된 위협 모의훈련, 역공학, 방어·학술 목적의 악성코드 분석이 포함된다. 악성코드 제작, 재배포와 재판매는 금지된다. 피싱에 강한 다중인증, 사용자별 인증, 내부 보안·사고대응·모의침투팀으로의 접근 제한, 직원 사용 기록도 요구된다.

3.7에서 3.8로 옮길 때는 운영 트래픽을 한 번에 바꾸기보다 같은 요청을 두 모델에 보내 결과만 비교하는 그림자 시험이 안전하다. 한국어 지시 준수, 함수 호출 성공률, 전체 지연, 재시도와 출력 토큰을 함께 기록하면 초당 토큰이 빨라도 작업 종료가 늦는 경우를 찾을 수 있다. 가격이 바뀌는 2027년 시나리오도 같은 표본으로 다시 계산해야 한다.

Fairwind의 심사는 단순 신청 순서가 아니다. Google DeepMind는 지원 조직의 보안 이력과 윤리적 운영 기록을 확인하고, 정부·국가 사이버기관과 핵심 인프라·기술 플랫폼을 우선한다고 설명한다. 방어 벤치마킹을 하는 학술 연구실도 신청할 수 있지만 학생에게는 공개 모델을 쓰는 CodeMender를 권한다. ‘전 세계 650곳 이상과 협력한다’는 숫자도 Fairwind 전체 파트너 규모이지, 3.8 Flash Cyber의 유료 고객 수나 한국 승인 기관 수로 읽어서는 안 된다.

접근을 제한한 이유는 일반 3.8과 안전 설정이 같지 않기 때문이다. 범용 Flash에는 화학·생물·방사능·핵과 사이버 공격 오용 방지 장치가 적용되지만, Cyber는 방어 전문가가 더 폭넓은 작업을 수행하도록 사이버 제한을 완화했다. 직접 관리형 모델로 Gemini Enterprise Agent Platform에서 이용할 때는 제로 데이터 보존을 지원할 수 있다고 명시돼 있지만, 이는 모든 연동 방식에 자동 적용되는 약속이 아니라 승인·계약·배포 경로를 확인해야 하는 옵션이다.

Google이 제시한 현장 사례도 공개 벤치마크와 분리해 읽어야 한다. Chrome 보안팀은 더 큰 상용 모델보다 올바른 패치를 2.6배 많이 만들었다고 했고, Wiz는 내부 침투 시험에서 재현율이 7.5~9.7%포인트 높으면서 비용은 2.3~5.2배 낮았다고 밝혔다. Google Cloud 연구팀은 두 시간 안에 중대한 기반 취약점을 찾았다고 설명했다. 그러나 표본, 비교 모델, 실패 사례와 전체 실행 비용이 공개되지 않은 자사·파트너 평가이므로 독립 재현 결과로 볼 수 없다.

‘20개 프로그래밍 언어에서 70%를 넘겼다’는 결과 역시 Google의 비공개 내부 평가다. 언어별 표본 수, 성공 기준, 비교 모델과 실패 분포가 공개되지 않아 CyberGym이나 CWE-Bench 수치와 합산하거나 평균내서는 안 된다. 일반 3.8 Flash의 공개 모델 카드도 제한을 완화한 Cyber 전용 모델 카드를 대신하지 않으므로, 실제 도입 심사에서는 별도의 허용 작업과 금지 작업을 계약서로 확인해야 한다.

승인 뒤에도 모델에게 운영망 전체를 바로 열어 줄 이유는 없다. 시험용 계정과 격리된 복제 환경에서 시작하고, 취약점 재현에 사용한 입력·도구·결과와 사람이 승인한 시점을 남겨야 한다. 비밀키와 고객 자료는 작업 목적에 필요한 최소 범위만 제공해야 나중에 오탐과 실제 공격 신호를 구분할 수 있다.

보안 성능이 높아질수록 결과의 취급도 중요해진다. 모델이 만든 재현 코드는 수정이 끝날 때까지 접근을 제한하고, 외부 공개 전에는 공급자 통지와 조직의 취약점 공개 절차를 따른다. Fairwind 승인은 한 조직의 모든 사용을 안전하다고 인증하는 도장이 아니라, 정해진 목적과 통제 아래 더 넓은 기능을 쓰게 하는 출입 조건이다.

구글은 CyberGym에서 86.2점을 제시했지만 차상위 GPT-5.5-Cyber의 85.6%와는 0.6%포인트 차이다. 이 평가는 알려진 취약점 설명과 패치 전 코드를 바탕으로 재현 코드를 만드는 과제가 중심이어서, 아무 단서 없이 새로운 취약점을 발견하는 능력과 같지 않다. CyberGym도 작은 점수 차이의 과대해석을 경고한다.

CWE-Bench의 비공개 100개 과제에서는 Flash Cyber가 47.2%로 Fable 5의 47.8%보다 낮았고, 3.7 Flash의 44.0%보다 높았다. 한 실행의 비용은 Cyber 3.64달러, 3.7 Flash 1.43달러, GPT-5.6 Sol 2.29달러였다. 모델마다 사용한 에이전트 도구도 달라 이 숫자를 순수 모델 능력만의 순위로 보면 안 된다.

한국 이용자는 일반 모델과 데이터 위치를 따로 봐야 한다

구글코리아 발표는 일반 3.8 Flash를 AI Studio와 API, Android Studio, Gemini Enterprise, Pro·Ultra 구독자의 Gemini 앱·AI 모드·Sheets에 제공한다고 안내한다. API 지원 국가 목록에도 대한민국이 포함돼 있어 일반 모델은 한국에서 사용할 근거가 분명하다.

그러나 한국에서 호출할 수 있다는 사실이 데이터가 서울에만 머문다는 뜻은 아니다. 기업은 사용하는 API와 Cloud 제품의 처리 위치, 보존 정책, 검색 근거 연결 때 외부로 나가는 정보, 무료·유료 티어의 데이터 사용 조건을 각각 확인해야 한다.

도입을 검토한다면 먼저 실제 한국어 문서와 코드 저장소로 품질·지연·총 토큰을 함께 재본다. 그다음 2027년 가격으로 월 비용을 다시 계산하고, 시간 초과와 도구 실패 때 재시도 한도를 둔다. 보안 업무라고 해서 Cyber 승인을 전제로 설계하지 말고 일반 모델에서 허용되는 방어 작업 범위를 기준으로 시작하는 편이 현실적이다.

가장 흔한 두 가지 오해

Flash Cyber는 누구나 쓰는 새 공개 API가 아니며, 입력 0.75달러·출력 3.75달러는 영구 가격이 아니다. 접근 권한과 2027년 비용을 따로 확인해야 한다.

Gemini 3.8 Flash의 핵심은 정식 출시된 빠른 범용 모델이라는 점이고, Flash Cyber의 핵심은 강한 사이버 기능을 승인된 방어 조직에만 여는 통제된 경로라는 점이다. 같은 발표에 담겼지만 구매와 운영 판단은 두 모델을 분리해 해야 한다.
