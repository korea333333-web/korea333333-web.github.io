알리바바, 그림을 8단계로 만드는 Qwen Image Turbo 공개

중국 알리바바의 Qwen 개발팀이 10월 9일 이미지 생성·편집 모델 ‘Qwen Image 2.1 Turbo’를 공개했다. 글로 설명해 새 그림을 만들거나 기존 사진을 고치는 AI로, 그림을 완성하는 계산을 8단계로 수행한다. 직접 실행할 모델과 알리바바 클라우드를 통해 호출하는 API를 함께 제공한다.

여기서 8단계는 그림을 다듬는 계산 횟수다. 8초 안에 끝난다는 시간 약속이나 8배 빨라졌다는 성능 수치와는 다르다. 개발팀의 공개 기록은 9월 20일 기본 모델을 먼저 내놓고, 10월 9일 그 모델을 빠르게 실행하도록 만든 Turbo와 API를 추가했다고 설명한다.

한 번의 결과보다 여러 번 고치는 작업에 가깝다

이미지 AI는 처음부터 완성된 사진을 바로 꺼내기보다, 여러 계산을 거치며 모양을 정돈한다. Qwen Turbo의 8단계는 이 반복을 줄인 실행 방식이다. 공식 안내는 글에서 새 그림을 만드는 작업과 입력 그림을 수정하는 작업 모두에 같은 8단계 설정을 사용한다.

기본 모델의 예제는 40단계 계산을 사용하지만 Turbo는 미리 저장된 8단계 순서를 불러온다. 이 둘을 실행 시간의 배수로 바꿔 말할 수는 없다. 그림 크기, 사용하는 컴퓨터, 입력 자료를 읽는 시간도 전체 대기 시간에 영향을 준다. Turbo 모델 설명서는 단계 설정을 안내하지만 모든 장비에 공통인 속도는 제시하지 않는다.

제작자가 체감할 지점은 여러 후보를 만들고 다시 고치는 과정이다. 예를 들어 상품 소개 그림의 구도는 유지하면서 배경색을 바꾸고, 가로형과 세로형을 비교하는 작업을 생각할 수 있다. 이런 반복에서 최종적으로 쓸 수 있는 결과가 얼마나 빨리 나오는지가 중요하다. 한 번의 생성 시간이 짧아도 수정 횟수가 늘면 전체 작업은 길어진다.

그림을 새로 만들고, 배경을 비우고, 일부만 고친다

Qwen Image 2.1 계열은 새 이미지 생성과 기존 이미지 편집을 하나의 모델에서 다룬다. 사진 속 대상을 따로 떼어 내거나, 배경이 투명한 그림을 만들고, 수정할 부분을 표시하는 방식도 지원한다. 개발팀은 참고 이미지 여러 장을 함께 쓰는 기능을 소개한다. 기본 모델의 기능 안내에서 확인할 수 있다.

투명 배경은 대상 뒤에 흰 종이가 남지 않고, 아래에 놓은 다른 그림이 비치는 상태다. 예를 들어 직접 만든 캐릭터를 영상의 구석에 올릴 때 별도로 배경을 지우는 작업을 줄일 수 있다. 이미지 형식의 RGBA에서 A는 픽셀마다 얼마나 투명한지 담는 값이다.

부분 수정은 사진 전체를 새로 만드는 대신 바꿀 위치를 알려 주는 기능이다. 기본 모델 안내에는 원으로 표시하거나 색을 칠하고, 수정 범위를 따로 만든 그림으로 전달하는 방법이 나온다. 사진의 나머지 요소를 유지하면서 특정 부분을 고치고 싶은 제작 작업에 맞는 기능이다.

이 기능들은 기존 2.1 계열에서 이어진다. 이번 Turbo 발표의 새 핵심은 같은 계열의 이미지 생성과 편집을 8단계 계산으로 제공한다는 점이다. 기본 기능의 이름과 새로 달라진 실행 방식을 나눠 보면, 모델을 통째로 새 제품처럼 받아들이는 혼란이 줄어든다.

직접 실행할 모델과 클라우드 서비스는 따로 고른다

직접 실행하는 경로에서는 모델 파일을 내려받아 이미지 생성 프로그램으로 불러온다. 모델 파일은 AI가 학습한 계산 규칙을 담은 자료다. Turbo 안내는 이를 실행하는 소프트웨어와 권장 설정을 제공한다. 내려받기만 하면 모든 노트북에서 곧바로 같은 속도로 작동하는 형태는 아니다.

공식 설명에 나오는 약 70억 개의 수치는 이미지를 만드는 부분의 계산값 규모다. 이 계산값을 파라미터라고 부른다. 화면에 찍히는 점의 수인 해상도나 파일 용량을 뜻하지 않는다. 필요한 장비를 판단할 때에는 이 수치 하나보다 실행 프로그램과 메모리 조건을 함께 보게 된다.

Turbo는 권장 계산 순서를 모델 파일에 저장해 불러오도록 했다. 기술 설정을 직접 바꾸는 개발자에게는 중요한 차이다. 공식 모델 설명서는 계산 횟수 옵션 하나를 바꾸는 것만으로 저장된 순서가 덮어써지지 않는다고 안내한다. 일반 제작자는 사용하려는 프로그램이 Turbo를 제대로 지원하는지부터 확인하는 편이 간단하다.

API는 모델을 내 컴퓨터에서 돌리지 않고 외부 서비스에 생성 요청을 보내는 연결 방식이다. 프로그램에서 이미지 설명과 입력 사진을 보내고 결과를 돌려받는다. 장비 운영은 서비스가 맡지만 호출 요금이 발생한다. 개발팀은 같은 날 Pro와 Turbo API의 제공도 알렸다.

API는 장당 요금, 공개 모델은 연구용 허락

10월 12일 확인한 알리바바 클라우드 공식 요금표에서 싱가포르 경로의 Turbo 출력 요금은 이미지 한 장당 미화 0.016달러다. 같은 표의 Pro는 0.04달러다. 다른 지역에는 별도 가격이 있으므로 계정에서 선택한 제공 지역을 기준으로 계산한다.

이 가격으로 Turbo 이미지 100장이 정상 생성되면 출력 요금 단순 합계는 1.60달러다. 이는 무료 제공량·세금·환율 등을 반영하지 않은 계산 예다. 결과가 마음에 들지 않아 새 이미지를 여러 장 만들면 정상 생성된 장수만큼 비용이 더해진다.

공개 모델의 사용 허락은 클라우드 호출 요금과 별개다. Qwen Research License는 공개 자료를 연구·평가 목적의 비상업적 용도로 허용하고, 상업적으로 사용하려면 별도 라이선스를 받도록 규정한다. 코드와 모델을 공개했다는 소개만 보고 업무용 서비스에 자유롭게 넣어서는 안 된다.

따라서 광고 제작이나 유료 서비스에 연결하려는 사람은 먼저 어떤 경로로 사용할지 정해야 한다. 직접 실행한다면 공개 모델의 상업용 허락을, 클라우드 API를 쓴다면 해당 서비스의 이용 조건과 요금을 확인한다. 개발팀의 공개 라이선스와 호스팅 서비스 계약을 같은 조건으로 섞지 않는 것이 출발점이다.

한국어 문구는 작은 완성본에서 확인한다

공식 예제에는 글자가 들어간 포스터와 여러 종류의 이미지가 있다. 다만 공개 시연만으로 한국어 제목의 정확성이나 반복 편집 결과를 모두 판단할 수는 없다. 편집부는 썸네일 제작을 시험한다면 짧은 한글 제목, 대상의 형태, 세로·가로 화면에서의 잘림을 별도로 보는 방법을 권한다.

이번 발표에서 확실히 달라진 것은 Qwen의 그림 생성·편집을 8단계로 실행하는 선택지가 생겼다는 점이다. 빠르게 후보를 비교하려는 제작자에게는 관심을 가질 만한 변화다. 실제 작업에 넣을 때는 결과의 품질, 정상 생성된 장수에 따른 비용, 사용할 수 있는 라이선스를 함께 판단하면 된다.
