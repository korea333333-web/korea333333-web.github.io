챗GPT 이용 안내 · 발표 2026.09.25

오픈AI, 챗GPT에서 계정 접속과 보안 설정 변경 기록을 보여준다

오픈AI가 챗GPT에 ‘보안 기록’ 메뉴를 도입한다고 9월 25일 안내했다. 내 계정에 언제 로그인하고 로그아웃했는지, 비밀번호나 추가 인증 방법이 언제 바뀌었는지를 웹에서 확인할 수 있다.

어디서 확인하나

컴퓨터나 휴대전화의 웹브라우저에서 챗GPT를 연다. 설정으로 들어가 ‘보안 및 로그인’을 선택한 뒤 ‘보안 기록’을 누르면 된다. 영어 화면에서는 Settings → Security and login → Security history라고 표시된다. 오픈AI가 공개한 경로는 웹 화면 기준이다.

기록에는 로그인과 로그아웃, 비밀번호 변경, 여러 단계 인증 설정 변경 등이 나타난다. 여러 단계 인증은 비밀번호를 입력한 뒤 휴대전화나 보안 키로 한 번 더 본인임을 확인하는 방식이다. ‘패스키’는 비밀번호 대신 기기의 잠금 해제 기능 등을 이용해 로그인하는 방법이다.

사건마다 시간과 대략적인 위치, 사용한 기기 정보도 볼 수 있다. 예를 들어 내가 어젯밤 서울의 노트북에서 접속했는데 기록에는 모르는 기기와 다른 시각의 로그인이 나온다면 한 번 더 살펴볼 이유가 있다. 위치는 인터넷 연결 방식 때문에 정확하지 않거나 아예 나오지 않을 수 있다. 위치 한 줄만으로 누가 들어왔다고 단정하지 말고 시각과 기기를 함께 보자.

낯선 접속이 보이면 무엇을 하나

먼저 날짜와 기기, 사용한 로그인 방법을 확인한다. 가족이나 동료가 쓰는 공유 컴퓨터에서 내 계정으로 접속했을 수도 있고, 여행 중 사용한 기기가 뒤늦게 떠오를 수도 있다. 직접 한 일이 아니라면 바로 계정을 보호해야 한다.

비밀번호를 쓰는 계정이라면 비밀번호를 새것으로 바꾼다. 다른 사이트와 같은 비밀번호를 썼다면 그 사이트도 살펴본다. 다음으로 오픈AI의 보안 안내에 따라 모든 기기에서 로그아웃하고 추가 인증을 켠다. 오픈AI는 추가 인증을 켜는 것만으로 이미 열린 로그인 상태가 끝나지는 않는다고 설명한다. 순서가 중요하다.

현재 로그인된 기기를 직접 보고 싶다면 ‘보안 기록’ 옆의 ‘활성 세션’을 확인한다. 세션은 기기나 브라우저에서 로그인한 상태를 뜻한다. 오픈AI의 활성 세션 안내에 따르면 기기별 로그아웃 또는 전체 로그아웃을 할 수 있다. 조직의 회사 로그인 방식으로 연결된 계정은 이 메뉴가 제공되지 않을 수 있다.

모든 기기에서 로그아웃하면 지금 보고 있는 기기에서도 로그아웃된다. 다른 기기에 반영되기까지 최대 30분이 걸릴 수 있다. 그 사이에 다시 로그인하라는 메시지가 나와도 놀라지 않도록 새 비밀번호와 추가 인증 수단을 먼저 준비하면 좋다.

보안 기록과 활성 세션은 어떻게 다른가

보안 기록은 ‘무슨 일이 언제 있었나’를 보는 장부다. 로그인, 로그아웃, 보안 설정 변경 같은 과거 사건을 확인한다. 활성 세션은 ‘지금 어느 기기가 로그인 상태인가’를 관리하는 화면이다. 낯선 기록을 발견했을 때는 활성 세션으로 가서 해당 기기나 모든 기기의 로그인을 끝낼 수 있다.

예를 들어 보안 기록에 지난주 로그인 한 건이 있는데 활성 세션에는 그 기기가 없을 수 있다. 이미 로그아웃했기 때문이다. 반대로 현재 로그인된 기기가 활성 세션에 있는데 보안 기록의 시간·위치 설명이 모호할 수도 있다. 두 화면은 서로 다른 질문에 답한다.

이 기능은 계정 도용이 실제로 일어났다고 알려 주는 자동 판정기가 아니다. 내가 하지 않은 변경이 있는지 스스로 확인할 단서를 제공한다. 오픈AI 도움말도 시간과 기기 정보를 함께 보라고 안내한다.

한국 사용자도 바로 볼 수 있나

오픈AI의 출시 안내에는 특정 국가나 요금제만 사용할 수 있다는 조건이 적혀 있지 않다. 다만 ‘도입 중’이라고 표현돼 있어 모든 계정에 같은 순간 메뉴가 나타나는지는 별도로 확인해야 한다. 내 화면에 아직 메뉴가 없다면 웹에서 다시 확인하고 계정 유형에 따른 안내를 살펴보면 된다.

회사에서 제공한 로그인 계정은 개인 계정과 보안 메뉴가 다를 수 있다. 특히 조직의 통합 로그인으로 쓰는 계정은 활성 세션 기능이 제한될 수 있다고 오픈AI는 안내한다. 보안 기록 자체와 활성 세션 기능을 같은 것으로 혼동하지 않는 것이 좋다.

챗GPT를 자주 쓴다면 지금 설정에서 보안 기록이 보이는지 확인해 두자. 문제가 생긴 뒤 처음 메뉴를 찾는 것보다, 평소 내 기기 목록과 최근 접속 시간을 알아두는 편이 낯선 변화를 알아보기 쉽다.

기록에서 눈여겨볼 변화

평소 같은 노트북과 휴대전화로만 접속했다면 새로운 기기에서 로그인한 기록이 눈에 띈다. 내가 잠든 시각에 비밀번호가 바뀌었다면 더 서둘러 확인해야 한다. 보안 기록은 사건 종류를 보여 주므로 단순한 로그인과 보안 설정 변경을 따로 읽을 수 있다. 낯선 기록이 보이면 화면에 표시된 시각과 기기 정보를 적어 두자.

하지만 위치가 낯설다는 이유 하나로 계정이 뚫렸다고 확정할 수는 없다. 휴대전화 통신망이나 회사 인터넷은 접속 위치를 다른 도시로 표시할 수 있다. 여행 중 사용한 브라우저, 새로 설치한 앱도 기억해 보자. 내가 설명할 수 없는 기기와 시간, 보안 설정 변경이 함께 보이면 비밀번호 변경과 로그아웃을 미루지 않는 편이 안전하다.

오픈AI 계정으로 여러 서비스를 쓴다면 한 계정의 문제가 더 넓게 이어질 수 있다. 챗GPT뿐 아니라 개발자가 쓰는 API 플랫폼에도 같은 로그인 보호가 적용된다. API는 프로그램이 오픈AI 모델을 호출할 때 쓰는 서비스다. 개발자는 계정 접속 기록과 별도로 API 사용량과 비밀 접속 키가 노출되지 않았는지도 확인해야 한다.

API 비밀 키가 공개됐다면 비밀번호만 바꾸지 말고 그 키를 폐기해야 한다. 키는 프로그램이 본인 계정의 사용 권한을 증명할 때 쓰는 문자열이다. 누군가 복사했을 가능성이 있다면 새 키를 발급하고 예상 밖의 사용 요금이 있는지 살펴야 한다. 일반 챗GPT 이용자는 개발용 키가 없다면 이 단계까지 할 필요는 없다.

보안을 더 단단히 하려면

첫째, 다른 사이트에서 쓰지 않는 비밀번호를 사용한다. 같은 비밀번호를 여러 곳에 쓰면 다른 사이트에서 새어 나온 비밀번호로 챗GPT 계정까지 들어올 수 있다. 비밀번호 관리 도구를 쓰면 긴 비밀번호를 외우지 않아도 된다. 이미 노출이 의심되면 기존 비밀번호를 계속 쓰지 말고 바꾸자.

둘째, 계정에 제공되는 추가 인증 방법을 켠다. 인증 앱의 일회용 코드, 휴대전화 승인, 문자 메시지, 패스키 등 선택지는 계정과 국가·기기에 따라 다를 수 있다. 추가 인증이 켜져 있으면 비밀번호를 아는 사람도 두 번째 확인을 통과해야 한다. 설정한 인증 수단을 잃어버리지 않도록 복구 방법도 확인해 두면 좋다.

셋째, 이미 로그인된 기기를 살핀다. 추가 인증을 새로 켜도 전에 열어 둔 로그인 상태는 자동으로 끝나지 않는다. 의심스러운 활동이 있었다면 전체 로그아웃을 하고 다시 필요한 기기에서 로그인한다. 공유 컴퓨터에서 사용했다면 특히 이 단계를 확인하자.

마지막으로 피싱 링크에 주의한다. 피싱은 진짜 회사처럼 꾸민 가짜 페이지에 비밀번호를 입력하게 만드는 수법이다. 보안 경고 메일을 받았더라도 메일 속 링크를 바로 누르기보다 직접 챗GPT 주소를 열고 설정을 확인하면 안전하다. 보안 기록은 이런 의심을 확인할 단서이지, 가짜 사이트를 자동으로 막아 주는 기능은 아니다.

예를 들어 이렇게 확인할 수 있다

월요일 아침에 보안 기록을 열었더니 일요일 밤 새로운 기기에서 로그인한 내역이 보인다고 하자. 먼저 그 시각에 내가 새 브라우저를 썼는지 떠올린다. 기억나지 않으면 활성 세션에서 같은 기기가 아직 로그인돼 있는지 본다. 사용하지 않은 기기라면 로그아웃시키고 비밀번호를 바꾼다. 이때 표시된 위치가 이상해도 기기와 시간을 함께 확인하는 것이 중요하다.

다른 예로 내가 하지 않은 패스키 등록이나 추가 인증 해제 기록이 보인다면 더 급하다. 누군가 로그인 방법 자체를 바꿨을 수 있기 때문이다. 오픈AI의 보안 안내에 따라 계정 접근을 정리하고 지원팀에 문의한다. 문의할 때는 기록에 표시된 사건 종류와 시간, 기기 정보를 전달하면 조사에 도움이 된다.

보안 기록이 아무것도 보여 주지 않더라도 계정을 보호하는 기본 조치는 필요하다. 고유한 비밀번호와 추가 인증을 쓰고, 공유 컴퓨터에서 작업을 마친 뒤 로그아웃하자. 이 기능은 이미 일어난 일을 확인하기 쉽게 해 준다. 평소 안전한 로그인 습관까지 대신해 주지는 않는다.

처음 확인할 때는 최근 며칠의 로그인과 보안 설정 변경을 차례대로 읽어 보자. 내가 쓰는 휴대전화와 노트북의 접속 시간이 보이면 이후 낯선 기록을 찾기 쉬워진다. 화면에 보이는 세부 정보가 부족하면 무리하게 추측하지 말고, 의심되는 기기를 로그아웃하고 계정 보호 조치를 진행하면 된다.
