DeepSeek V4-Flash-0731, Claude Opus 4.8의 89분의 1 출력 단가로 어디까지 왔나

DeepSeek의 새 V4-Flash-0731은 ‘Claude Opus 4.8과 똑같은 모델’은 아니다. 같은 독립 평가에서 50점으로 Opus 4.8의 56점에 6점 뒤진다. 하지만 100만 토큰당 공식 출력 가격은 0.28달러로 Claude의 25달러보다 약 89배 싸고, 입력 가격도 약 36배 낮다. 여기에 MIT 라이선스의 공개 가중치까지 겹치면서 성능 1점보다 비용 1달러가 더 중요한 대규모 에이전트 시장의 계산법을 바꾸고 있다.

가장 먼저 구분할 것은 평가의 출처다. Artificial Analysis의 0731 독립 평가에서 DeepSeek V4-Flash-0731의 최대 추론 노력 점수는 Intelligence Index 50이다. 같은 기관의 Claude Opus 4.8 최대 노력 평가는 56이다. 서로 다른 회사가 자기 모델에 유리한 시험을 골라 적은 숫자가 아니라, 같은 기관의 현재 지수와 실행 방법을 적용한 비교라는 점에서 출발점으로 쓸 만하다.

6점 차이를 ‘동급’이라고 단정하면 과장이다. 이 지수는 실제 업무형 과제, 도구 사용, 터미널 코딩, 과학 추론, 어려운 지식, 장문 추론 등 아홉 평가를 묶는다. 모델마다 강점이 다르고 6점이 모든 업무에서 같은 격차를 뜻하지도 않는다. 정확한 표현은 DeepSeek가 최고 폐쇄형 모델 바로 아래의 상위권에 진입했지만, 종합 점수에서는 아직 Opus 4.8이 앞선다는 것이다.

DeepSeek 자체 시험은 에이전트 성향을 더 자세히 보여 준다. 7월 31일 공식 변경 기록에서 회사는 Terminal Bench 2.1 82.7, NL2Repo 54.2, Cybergym 76.7, DeepSWE 54.4, Toolathlon verified 70.3을 제시했다. 이전 Flash Preview와 V4-Pro Preview보다 코딩·도구 사용 성능이 크게 개선됐다는 주장이다.

다만 회사 수치에는 공개되지 않은 DeepSeek Harness와 최대 노력 설정이 들어갔다. 하네스, 토큰 예산, 반복 횟수는 에이전트 점수에 큰 영향을 준다. 따라서 82.7을 Claude의 다른 하네스 점수 옆에 바로 놓고 승패를 선언하기보다, 독립 기관이 같은 틀에서 얻은 50 대 56을 종합 비교에 사용하고 회사 표는 개선 방향을 읽는 보조 자료로 보는 편이 안전하다.

성능보다 더 극적인 숫자는 가격이다. DeepSeek 공식 가격표는 V4-Flash-0731의 100만 토큰당 캐시 미적중 입력 0.14달러, 출력 0.28달러를 제시한다. 캐시 적중 입력은 0.0028달러다. Anthropic의 Opus 4.8 발표에 적힌 일반 API 가격은 입력 5달러, 출력 25달러다.

가격 배수는 단가만 비교한 결과다. 에이전트가 같은 일을 끝내기 위해 더 많은 사고 토큰과 재시도를 쓰면 작업당 격차는 줄어든다. 반대로 반복되는 시스템 지시와 저장소 문맥이 캐시에 잘 적중하면 DeepSeek의 비용 우위는 더 커질 수 있다. 구매자가 기록해야 할 값은 100만 토큰 표의 숫자뿐 아니라 성공한 수정 한 건의 총 토큰, 대기시간, 재시도, 사람 검토시간이다.

DeepSeek 가격표에는 중요한 단서도 새로 붙었다. 회사는 베이징 시간 오전 9시~정오와 오후 2시~6시에 모든 과금 항목을 정가의 두 배로 받을 피크 요금제를 예고했다. 시행일은 아직 발표되지 않았다. 두 배가 되어도 Claude와의 격차는 크지만, ‘항상 0.14달러와 0.28달러’라고 고정해 예산을 세우면 안 된다.

모델 구조가 이 경제성을 뒷받침한다. 공식 모델 카드에 따르면 V4-Flash는 전체 2,840억 매개변수 가운데 토큰마다 130억 개를 활성화하는 희소 혼합전문가 모델이다. 문맥 길이는 100만 토큰이며, 전문가 가중치는 FP4, 나머지 일부는 FP8을 섞어 배포한다. 모든 가중치를 매 토큰 계산에 쓰지 않는 구조가 낮은 추론비의 기반이다.

‘오픈소스’라는 말은 한 단계 더 정확히 써야 한다. 가중치와 실행 안내가 공개됐고 저장소 라이선스는 MIT라서 사용·수정·배포·상업 이용의 폭이 넓다. 그러나 32조 토큰이 넘는 전체 학습 데이터와 모든 데이터 정제 과정이 공개된 것은 아니다. 이 글에서는 검증 가능한 범위를 가리키기 위해 ‘MIT 오픈웨이트’라고 부른다.

또 하나의 구분은 0731 API와 내려받는 체크포인트다. 7월 31일 발표는 기존 구조를 유지한 사후학습 업데이트이며 DeepSeek API의 deepseek-v4-flash가 새 버전을 가리킨다. 공개 저장소의 체크포인트가 같은 날 같은 사후학습 상태로 갱신됐는지, 로컬 추론 엔진에서 API와 같은 동작을 내는지는 파일 버전과 모델 카드를 따로 확인해야 한다.

핵심 판단: DeepSeek의 경쟁력은 ‘오픈이면서 싸다’ 하나가 아니다. 상위권 에이전트 성능, 희소 구조, 공격적인 API 가격, 공개 가중치가 한 모델 안에서 연결됐다는 점이 중요하다. 어느 하나만 떼면 중국 LLM 전략의 윤곽이 흐려진다.

DeepSeek가 보여 주는 중국 LLM 전략의 네 단계

이번 모델을 중국의 공식 국가정책 그 자체라고 부를 수는 없다. DeepSeek는 민간 기업이고 가격과 공개 범위는 회사가 정한다. 다만 국가의 AI Plus 방향, 지방정부의 오픈소스 생태계 계획, 국내 가속기 호환, 중국 연구소들의 반복된 공개 가중치 출시를 겹쳐 보면 산업 전략의 윤곽은 비교적 선명하다.

첫 단계는 컴퓨팅 제약을 제품 설계 문제로 바꾸는 것이다. V4-Flash는 2,840억이라는 큰 저장 규모를 유지하면서 토큰당 활성 매개변수를 130억으로 줄였다. DeepSeek의 V4 기술 설명은 100만 토큰 문맥에서 이전 V3.2보다 단일 토큰 추론 연산과 KV 캐시를 크게 줄였다고 밝힌다. 미국의 최상위 칩 공급이 제한된 환경에서 성능당 연산량은 곧 제품 경쟁력이다.

둘째는 최고 성능을 독점적인 고가 API에만 묶지 않는 것이다. DeepSeek의 단가는 개발자가 더 많은 도구 호출과 긴 작업을 시도하게 만들고, 경쟁사에도 가격 인하 압력을 준다. 최근 Axios가 새 버전을 AI의 ‘바닥을 향한 가격 경쟁’으로 해석한 이유다. 값싼 모델이 충분히 좋아지는 순간 최고점보다 작업량이 시장을 넓힌다.

셋째는 공개 가중치를 유통 전략으로 쓰는 것이다. 모델을 내려받은 클라우드와 하드웨어 회사는 각자 더 싼 추론 서비스를 만들 수 있고, 연구자는 양자화·파인튜닝·안전 평가를 붙인다. 이는 API 매출 일부를 포기하는 대신 표준과 개발자 습관을 넓히는 선택이다. 폐쇄형 모델과 달리 공급사 정책이 바뀌어도 체크포인트를 보유한 조직은 자체 배포를 이어갈 수 있다.

넷째는 모델을 산업과 하드웨어 정책에 연결하는 것이다. 중국의 2026년 정부 업무보고는 AI Plus를 확대하고 에이전트와 지능형 단말의 대규모 상용화를 추진한다고 밝혔다. 베이징의 2026~2028년 오픈소스 생태계 계획은 국내 오픈소스 프로젝트와 산업별 대형 모델, 모델 개발과 컴퓨팅 스케줄링을 잇는 플랫폼을 목표로 한다. 이 문맥에서 오픈웨이트는 홍보가 아니라 응용 확산용 인프라다.

그러나 개방 전략이 무조건적인 개방을 뜻하지는 않는다. 중국 내 공개 생성형 AI 서비스는 콘텐츠·데이터·보안 규제를 받으며, 모델이 정치적으로 민감한 질문에 어떻게 답하는지는 별도 위험이다. 가중치를 내려받을 수 있다는 사실은 편향과 검열 가능성을 없애지 않는다. 자체 호스팅을 하더라도 한국어·중국어 정치 문항, 출처 제시, 거부 패턴을 별도로 감사해야 한다.

하드웨어 자립도 아직 완성된 사실로 읽으면 안 된다. AP의 V4 출시 보도는 Huawei 가속기 지원이 미국 칩 의존도를 줄이는 신호라고 전했다. 호환과 대규모 훈련·추론의 경제성은 다른 문제다. 실제 처리량, 장애율, 소프트웨어 도구, 공급량이 따라와야 모델과 국산 칩의 결합이 상업적 대안이 된다.

한국 기업이 지금 확인할 세 가지

첫째, 같은 에이전트 안에서 업무당 비용을 재야 한다. 최근 완료한 개발 이슈 30~50개를 익명화하고 DeepSeek와 Claude에 같은 도구, 시간, 토큰 예산을 준다. 성공률, 병합 가능한 수정, 재시도, 잘못 건드린 파일, 사람 검토시간을 함께 기록하면 36배·89배의 단가 차이가 실제 업무에서 얼마나 남는지 알 수 있다.

둘째, 배포 경로별 데이터 위험을 나눠야 한다. DeepSeek 공식 API, 제3자 클라우드, 자체 호스팅은 같은 모델 이름을 써도 로그 보존, 지역, 업데이트, 장애 대응이 다르다. 민감한 소스코드와 개인정보가 있다면 가장 싼 API보다 데이터가 어디로 가고 누가 운영하는지를 먼저 확정해야 한다.

셋째, 공개 가중치의 운영비를 빠뜨리지 말아야 한다. 2,840억 매개변수 전체를 저장하고 여러 가속기에 나누는 비용, 추론 엔진 최적화, 보안 패치, 회귀시험, 모니터링은 무료가 아니다. 요청량이 작으면 공식 API가 더 싸고, 높은 사용량과 데이터 통제가 중요할 때 자체 배포가 의미를 가질 수 있다.

텍스트 전용이라는 제한도 분명하다. Claude Opus 4.8은 이미지 입력을 지원하지만 V4-Flash는 공식 모델 카드상 텍스트 입력·텍스트 출력 모델이다. 화면을 보고 클릭하거나 도면과 사진을 함께 분석하는 업무에서는 별도의 비전 모델과 오케스트레이션이 필요하다. 종합 지수 6점 차이보다 이 기능 차이가 구매 결정에 더 중요할 수 있다.

앞으로 볼 지표는 독립 평가의 유지 여부, 0731 체크포인트와 API의 일치, 피크 요금제 시행일, V4-Pro 업데이트, 제공자별 속도와 장애율이다. Artificial Analysis 지수가 다시 바뀌면 이전 50 대 56을 고정된 진리로 인용하지 말고 평가 버전과 날짜를 함께 적어야 한다.

필자의 결론은 DeepSeek가 Claude Opus 4.8을 완전히 따라잡았다는 것이 아니다. 더 중요한 변화는 독립 종합 지수에서 50 대 56까지 간격을 좁힌 오픈웨이트 모델이 출력 단가를 약 89분의 1로 낮췄다는 점이다. 중국 LLM 전략은 가장 큰 모델 한 번으로 승부하기보다 효율, 가격, 공개 가중치, 산업 확산을 한 고리로 묶는 쪽으로 선명해지고 있다. 이 고리가 유지된다면 다음 경쟁의 기준은 ‘누가 1등인가’에서 ‘누가 충분히 좋은 지능을 가장 넓게 배포하는가’로 이동할 가능성이 크다.
