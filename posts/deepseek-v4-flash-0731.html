중국 DeepSeek, Claude의 89분의 1 출력 가격…성능은 6점 뒤져

중국 AI 기업 DeepSeek가 7월 31일 V4-Flash-0731이라는 새 모델을 내놨다. 독립 평가 점수는 50점으로 Claude Opus 4.8의 56점보다 6점 낮다. 그러나 AI가 답을 만들어 내는 분량인 출력 100만 토큰의 공식 가격은 0.28달러로 Claude의 25달러보다 약 89배 싸다. 입력 가격도 약 36배 낮고, 모델 파일은 MIT 라이선스로 공개됐다. 최고 성능은 아니지만 많은 일을 아주 싸게 처리해야 하는 회사에는 계산이 달라질 수 있다.

먼저 성능 숫자가 어디서 나왔는지 봐야 한다. Artificial Analysis의 0731 독립 평가에서 DeepSeek V4-Flash-0731은 최대 추론 노력 설정으로 Intelligence Index 50점을 받았다. 같은 기관이 Claude Opus 4.8을 최대 노력 설정으로 시험한 결과는 56점이다. 두 회사가 각자 유리한 시험을 골라 낸 숫자가 아니라, 한 독립 기관이 같은 기준으로 비교한 결과다.

그렇다고 6점 차이를 무시하고 두 모델이 같다고 말하면 과장이다. 이 지수는 실제 업무, 도구 사용, 터미널 코딩, 과학 추론, 어려운 지식, 장문 추론 등 아홉 가지 평가를 합친다. 업무마다 차이는 달라질 수 있지만 종합 점수에서는 Opus 4.8이 앞선다. 현재 근거에 맞는 표현은 DeepSeek가 최고급 폐쇄형 모델 바로 아래까지 따라온 저비용 모델이라는 것이다.

DeepSeek가 공개한 자체 시험은 어떤 일이 좋아졌는지 보여 준다. 7월 31일 공식 변경 기록에서 회사는 Terminal Bench 2.1 82.7, NL2Repo 54.2, Cybergym 76.7, DeepSWE 54.4, Toolathlon verified 70.3을 제시했다. 이전 Flash Preview와 V4-Pro Preview보다 코딩과 도구 사용 능력이 크게 좋아졌다는 회사의 주장이다.

이 회사 수치를 다른 모델 점수와 바로 비교하면 안 된다. 시험에는 자세히 공개되지 않은 DeepSeek Harness와 최대 노력 설정이 쓰였다. 하네스는 AI에게 도구를 주고 일을 진행시키는 실행 환경이다. 이 환경과 토큰 예산, 재시도 횟수가 바뀌면 점수도 크게 달라진다. 그래서 종합 비교에는 독립 기관의 50 대 56을 쓰고, 82.7 같은 회사 점수는 개선 방향을 보는 자료로만 쓰는 편이 안전하다.

가격 차이는 더 크다. DeepSeek 공식 가격표에서 V4-Flash-0731은 100만 토큰을 읽을 때 0.14달러, 답을 만들 때 0.28달러다. 이전 질문 내용을 재사용하는 캐시가 맞으면 입력 가격은 0.0028달러까지 내려간다. Anthropic의 Opus 4.8 발표에 나온 일반 API 가격은 입력 5달러, 출력 25달러다.

하지만 가격표만 보고 실제 업무 비용이 89분의 1이라고 단정할 수는 없다. DeepSeek가 같은 일을 끝내려고 더 많이 생각하고 여러 번 다시 시도하면 차이는 줄어든다. 반대로 반복되는 지시와 저장소 내용을 캐시로 재사용하면 차이가 더 커질 수도 있다. 회사는 성공한 수정 한 건에 든 전체 토큰, 대기시간, 재시도 횟수, 사람의 검토시간을 함께 재야 한다.

가격표에는 앞으로 바뀔 조건도 있다. DeepSeek는 베이징 시간 오전 9시~정오와 오후 2시~6시에 모든 항목을 정가의 두 배로 받는 피크 요금제를 예고했다. 시행일은 아직 발표하지 않았다. 두 배가 돼도 Claude보다 싸지만, 언제나 0.14달러와 0.28달러라고 고정해 예산을 잡으면 안 된다.

싼 가격은 모델의 작동 방식과 관련이 있다. 공식 모델 카드에 따르면 V4-Flash는 전체 2,840억 개의 매개변수를 갖고 있지만, 글자 조각 하나를 처리할 때는 130억 개만 골라 쓴다. 큰 전문가 조직을 두고 질문마다 필요한 부서만 불러 일하게 하는 것과 비슷하다. 문맥 길이는 100만 토큰이고, 전문가 가중치는 FP4, 나머지 일부는 FP8로 압축해 배포한다. 전체를 매번 계산하지 않으니 비용을 줄일 수 있다.

다만 이를 완전한 ‘오픈소스’라고 부르기보다 공개 범위를 구분해야 한다. 모델의 핵심 파일인 가중치와 실행 방법이 공개됐고, 저장소 라이선스는 MIT다. 사용·수정·배포·상업 이용의 폭이 넓다. 하지만 32조 토큰이 넘는 전체 학습 데이터와 모든 정제 과정까지 공개된 것은 아니다. 그래서 이 글에서는 ‘MIT 오픈웨이트’라고 부른다.

7월 31일 API 업데이트와 내려받는 모델 파일도 같은 것으로 가정하면 안 된다. 이번 발표는 기존 구조를 유지한 사후학습 업데이트이며, DeepSeek API의 deepseek-v4-flash가 새 버전을 가리킨다. 공개 저장소 파일이 같은 날 같은 학습 상태로 바뀌었는지, 직접 설치했을 때 API와 똑같이 동작하는지는 파일 버전과 모델 카드를 따로 확인해야 한다.

핵심 판단: DeepSeek의 장점은 단순히 싸다는 데 있지 않다. AI가 도구를 써서 일을 처리하는 능력은 상위권에 들어왔고, 질문마다 필요한 부분만 계산해 비용을 낮췄으며, 다른 회사가 직접 운영할 수 있도록 모델 파일도 공개했다. 이 세 가지가 한꺼번에 움직인다는 점이 중요하다.

한 모델에서 보이는 중국 AI의 네 가지 선택

DeepSeek 한 회사의 제품을 중국 정부 정책과 같은 것으로 보면 안 된다. DeepSeek는 민간 기업이고 가격과 공개 범위도 회사가 정한다. 다만 중국 정부의 AI Plus 방향, 베이징의 오픈소스 계획, 중국산 가속기 지원, 여러 연구소의 공개 모델을 함께 보면 산업이 어느 쪽으로 움직이는지는 읽을 수 있다.

첫째, 제한된 컴퓨팅으로 더 많은 일을 하도록 모델부터 설계한다. V4-Flash는 2,840억 개를 저장하지만 글자 조각마다 130억 개만 깨운다. DeepSeek의 V4 기술 설명은 100만 토큰 문맥에서 이전 V3.2보다 토큰 하나를 만들 때 드는 계산과 KV 캐시를 크게 줄였다고 밝힌다. 미국의 최상위 칩 공급이 제한된 상황에서는 같은 연산으로 얼마나 좋은 결과를 내는지가 제품 경쟁력이 된다.

둘째, API 가격을 낮춰 개발자가 더 많은 실험을 하게 만든다. 값이 싸면 AI가 도구를 여러 번 호출하고 긴 작업을 반복해도 부담이 작다. 경쟁사도 가격을 내릴 압력을 받는다. Axios가 이번 버전을 AI의 ‘바닥을 향한 가격 경쟁’으로 해석한 이유다. 충분히 좋은 모델이 아주 싸지면 최고 점수보다 처리할 수 있는 작업량이 시장을 넓힌다.

셋째, 모델 가중치를 공개해 다른 회사가 배포하게 한다. 클라우드와 칩 회사는 더 싼 서비스를 만들고, 연구자는 모델을 압축하거나 특정 업무에 맞게 고치고 안전성을 시험할 수 있다. DeepSeek는 API 매출 일부를 포기하는 대신 개발자와 실행 환경을 넓힌다. 회사 정책이 바뀌어도 파일을 가진 조직은 자체 운영을 이어갈 수 있다.

넷째, 공개 모델을 산업과 하드웨어 정책에 연결한다. 중국의 2026년 정부 업무보고는 AI Plus 확대와 에이전트·지능형 단말의 대규모 상용화를 추진한다고 밝혔다. 베이징의 2026~2028년 오픈소스 생태계 계획은 국내 프로젝트, 산업별 대형 모델, 모델 개발과 컴퓨팅 배분을 잇는 플랫폼을 목표로 한다. 이 흐름에서 공개 가중치는 홍보물이 아니라 여러 산업이 AI를 가져다 쓰게 하는 기반이다.

파일 공개가 아무 제한도 없다는 뜻은 아니다. 중국에서 공개 생성형 AI 서비스를 운영하면 콘텐츠·데이터·보안 규제를 받는다. 정치적으로 민감한 질문에서 편향이나 검열이 나타날 가능성도 가중치를 내려받는다고 사라지지 않는다. 회사가 직접 운영하더라도 한국어·중국어 정치 질문, 출처 표시, 답변 거절 방식은 따로 시험해야 한다.

중국산 칩 지원도 곧바로 하드웨어 자립 완성을 뜻하지 않는다. AP의 V4 출시 보도는 Huawei 가속기 지원이 미국 칩 의존도를 줄이는 신호라고 전했다. 그러나 작동한다는 것과 대규모로 싸고 안정적으로 운영한다는 것은 다르다. 실제 처리량, 장애율, 개발 도구, 칩 공급량이 따라와야 상업적인 대안이 된다.

여기까지의 내용을 중국 AI 산업이 모델을 퍼뜨리는 방식과 실제 API 가격 차이로 나눠 보면 다음과 같다. 아래 두 그림은 공개 정책을 연결한 기사 해석과 회사들의 공식 가격표를 서로 구분해 정리했다.

한국 기업은 가격표보다 ‘끝낸 일의 비용’을 재야 한다

첫 시험은 같은 업무로 해야 한다. 최근 끝낸 개발 이슈 30~50개에서 민감한 내용을 지우고, DeepSeek와 Claude에 같은 도구·시간·토큰 예산을 준다. 성공률, 실제로 합칠 수 있는 코드, 재시도, 잘못 건드린 파일, 사람의 검토시간을 함께 기록해야 한다. 그래야 36배·89배의 단가 차이가 실제 업무에서도 얼마나 남는지 알 수 있다.

모델을 어디서 쓰는지도 나눠 봐야 한다. DeepSeek 공식 API, 제3자 클라우드, 자체 서버는 같은 모델 이름을 쓰더라도 로그 보관, 서버 지역, 업데이트, 장애 대응이 다르다. 민감한 소스코드와 개인정보가 있다면 가장 싼 곳보다 데이터가 어디로 가고 누가 운영하는지를 먼저 확인해야 한다.

공개된 모델 파일도 공짜로 운영되지는 않는다. 2,840억 개의 매개변수를 저장하고 여러 가속기에 나누는 장비, 실행 프로그램 최적화, 보안 패치, 이전 기능이 망가지지 않았는지 보는 회귀시험, 모니터링에 돈이 든다. 사용량이 작으면 공식 API가 더 쌀 수 있고, 요청이 많거나 데이터 통제가 중요할 때 직접 운영할 이유가 생긴다.

V4-Flash는 글만 읽고 쓰는 모델이라는 제한도 있다. Claude Opus 4.8은 이미지를 입력할 수 있지만, V4-Flash는 공식 모델 카드상 텍스트 입력·텍스트 출력 모델이다. 화면을 보고 클릭하거나 도면과 사진을 함께 분석하려면 별도의 이미지 인식 모델과 연결 장치가 필요하다. 종합 점수 6점 차이보다 이 기능 차이가 구매 결정에 더 중요할 수 있다.

앞으로는 독립 평가 점수가 유지되는지, 0731 모델 파일과 API가 같은 결과를 내는지, 피크 요금제가 언제 시작되는지, V4-Pro가 어떻게 바뀌는지, 서비스 제공자별 속도와 장애율을 봐야 한다. Artificial Analysis 지수가 바뀌면 50 대 56을 영원한 숫자처럼 쓰지 말고 평가 버전과 확인 날짜를 함께 적어야 한다.

DeepSeek가 Claude Opus 4.8을 완전히 따라잡은 것은 아니다. 중요한 점은 독립 평가에서 50 대 56까지 따라온 공개 모델이 답변 생성 가격을 약 89분의 1로 낮췄다는 것이다. 중국 AI 기업들은 모델 크기 하나로 승부하기보다 계산 효율, 싼 가격, 공개 파일, 산업 확산을 함께 묶고 있다. 이 흐름이 이어지면 경쟁의 질문도 ‘누가 1등인가’에서 ‘충분히 좋은 AI를 누가 가장 싸고 넓게 쓰게 하나’로 바뀔 수 있다.
