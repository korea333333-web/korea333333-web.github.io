머스크의 그록 4.7 출시…오래 걸리는 코딩과 문서 작업을 강화

일론 머스크의 AI 기업 SpaceXAI가 9월 21일 그록 4.7을 출시했다. 회사는 여러 시간 걸리는 코딩과 문서 작업을 이어가고, 자신이 만든 결과를 다시 검사하는 능력을 개선했다고 밝혔다. 기본 요금은 그록 4.6과 같다. 새 버전의 의미는 모든 경쟁사를 압도했다는 선언보다 같은 비용으로 더 긴 일을 맡기려는 변화에 있다.

짧은 답보다 오래 걸리는 일을 끝내는 데 초점을 맞췄다

예를 들어 홈페이지의 주문 기능을 고친다고 해 보자. 버튼 모양만 바꾸는 일이 아니라 주문 정보가 어디에 저장되는지, 결제가 끝난 뒤 어떤 화면이 나오는지, 취소할 때 기록은 어떻게 바뀌는지까지 살펴야 할 수 있다. 한 번 답하고 끝나는 질문과 여러 단계를 이어 수행하는 일은 필요한 능력이 다르다.

그록 4.7은 이런 긴 작업을 더 잘 처리하도록 학습했다고 회사는 설명한다. 더 큰 기본 모델에 어려운 문제를 오래 푸는 학습을 적용하고, 작업 결과를 다시 확인하는 능력을 강화했다는 것이다. 여기서 기본 모델은 새로운 훈련을 더하기 전 바탕이 되는 AI를 말한다. 그록 4.7 공식 발표

결과를 다시 확인한다는 것은 ‘다 했습니다’라고 말하는 단계에서 멈추지 않는다는 뜻이다. 예를 들어 코드를 고친 뒤 실제로 실행해 오류가 나는지 보고, 문제가 있으면 수정할 수 있다. 이런 과정에서 무엇을 시험했는지와 원래 요청을 제대로 만족했는지가 중요하다. 스스로 검사한다고 모든 실수가 없어지는 것은 아니다.

긴 일을 맡길 때는 앞서 받은 조건을 유지하는 능력도 필요하다. 처음에 ‘디자인은 그대로 두라’고 했는데 뒤에서 기능을 고치며 화면까지 바꾸면 사용자의 목적을 놓친 것이다. 앞선 자료와 지시를 계속 참고하면서 지금 고칠 부분을 판단하는 능력이 작업 품질에 영향을 준다.

사용료는 이전 버전과 같고, 빠른 별도 모델은 더 비싸다

공식 기본 요금은 입력 100만 토큰당 2달러, 출력 100만 토큰당 6달러다. 입력은 AI에게 주는 질문과 코드·자료이고, 출력은 AI가 만들어 내는 답과 코드다. 토큰은 이런 글의 양을 계산하는 작은 글 조각 단위로, 한글 한 글자나 영어 한 단어와 늘 같은 크기는 아니다.

그록 4.6에도 같은 기본 단가가 적용돼 있었다. 따라서 이번 소식을 ‘이전 버전보다 반값이 됐다’고 소개하면 맞지 않는다. 회사가 경쟁 제품과의 비교에서 강조한 가격과, 자기 회사의 이전 제품 대비 가격은 비교 대상이 다르다. 무엇과 비교한 숫자인지 제목 가까이에서 밝힐 필요가 있다.

회사 발표에는 출력 속도를 두 배로 높인 별도 빠른 모델도 나온다. 이 모델은 가격도 두 배라고 안내한다. 급하게 결과를 받고 싶은 일과 비용을 아끼며 오래 돌려도 되는 일을 나눠 선택할 수 있지만, 빠른 모델이 기본 가격에 제공된다고 읽으면 안 된다. 개발자 모델·요금 안내

여기서 출력 속도는 AI가 답을 써 내려가는 속도다. 전체 작업 완료 시간과 항상 같은 비율로 줄지는 않는다. 자료를 찾고 외부 도구가 일을 끝내길 기다리는 시간이 있다면 그 부분은 별도로 남기 때문이다. 답변이 두 배 빨리 써진다고 모든 업무가 정확히 절반 시간에 끝나는 것은 아니다.

총비용도 단가에 사용량을 곱해 봐야 한다. 같은 오류를 여러 번 고치느라 코드를 반복해서 읽고 쓰면 비용이 늘 수 있다. 반대로 한 번에 맞게 고치면 단가가 같아도 작업 비용은 줄어들 수 있다. 그래서 실제 이용자는 한 번 호출하는 가격뿐 아니라 원하는 결과까지 몇 번의 수정이 필요했는지를 함께 보면 된다.

코딩 도구와 개발자 연결에서 먼저 쓴다

그록 4.7은 Cursor와 Grok Build, 개발자 API 등에서 제공한다고 발표됐다. Cursor는 AI와 함께 프로그램 코드를 작성하고 고치는 편집 도구다. 기존에 Cursor로 작업하던 개발자에게는 새 모델을 작업에 넣어 볼 경로가 생긴 것이다. Cursor 공식 사이트

Grok Build는 그록으로 개발 작업을 하는 도구다. 모델은 일을 판단하는 AI이고, 이런 작업 도구는 파일과 실행 환경을 연결해 준다. 모델 이름만 알아도 바로 모든 파일을 고칠 수 있는 것은 아니며, 어떤 프로그램 안에서 어떤 권한으로 실행하는지가 함께 중요하다. Grok Build 안내

API는 개발자가 자기 프로그램에서 그록을 불러 쓸 때 이용하는 연결 방식이다. 글을 입력하고 답을 받는 기능을 서비스에 넣거나 반복 작업을 자동화하는 데 쓰인다. 일반 소비자용 앱의 모든 요금제와 모델 선택 화면이 같다는 뜻은 아니다. 출시 발표에서 명시한 이용 경로를 중심으로 보면 혼동이 줄어든다.

새 모델이 제공된다는 사실과 사용자의 현재 계정에서 이미 선택할 수 있다는 사실도 나뉜다. 사용하는 서비스가 모델을 연결하는 시점이나 이용 권한이 다를 수 있기 때문이다. 이번 기사에서는 각 계정으로 로그인해 실제 선택 화면을 시험하지는 않았다. 공식 제공 발표와 개인 계정 작동 확인을 구분했다.

개발자가 바꿔 볼 때도 처음부터 큰 서비스를 맡길 필요는 없다. 이전 모델이 어려워했던 작은 오류를 복사한 작업 공간에서 다시 풀게 할 수 있다. 원래 문제와 기대 결과가 분명하면 바뀐 능력을 판단하기 쉽다. 새 모델이라는 이유만으로 고객 자료를 바로 수정하도록 권한을 넓히는 것은 별개의 결정이다.

성능표에서 모든 항목이 최고인 것은 아니다

회사는 코딩과 업무 평가에서 개선된 수치를 제시했다. 이런 평가는 같은 유형의 문제를 여러 모델에 맡겨 결과를 비교한 시험이다. 이름이 낯선 평가라도 무엇을 시켰는지를 먼저 보면 이해하기 쉽다. 실제 프로그램을 고치는 시험인지, 문서를 작성하는 시험인지에 따라 결과의 의미가 다르다.

한 평가에서 높은 점수를 받았다고 모든 일에서 앞서는 것은 아니다. 공식 표에도 항목에 따라 다른 모델의 숫자가 더 높은 부분이 있다. 그록 4.7의 발전을 소개하면서 ‘이제 다른 AI는 필요 없다’고 결론 내리면 표에 있는 차이를 지워 버리는 셈이다.

작업 시간이 길다는 사실 자체가 성과는 아니다. 오랜 시간 실행됐어도 같은 오류를 반복했거나 마지막에 쓸 수 있는 결과가 없다면 사용자의 목적은 달성되지 않았다. 긴 일을 잘한다는 주장을 실제로 평가하려면 얼마나 오래 켜졌는지보다 필요한 산출물이 남았는지와 사람이 다시 고칠 분량을 함께 보는 편이 분명하다.

같은 조건인지도 함께 봐야 한다

모델이 오래 생각하도록 설정하면 더 나은 답을 얻을 수 있지만 시간과 비용도 늘어날 수 있다. 공식 비교표에는 이런 설정이 서로 다른 모델의 수치가 들어 있다. 동일한 설정 하나만으로 만든 완벽한 일대일 대결이라고 볼 수 없는 이유다. 회사의 발표와 독립적인 재현 시험도 구분된다.

예를 들어 한 사람은 참고서를 볼 수 있고 다른 사람은 보지 못한 시험이라면 점수만 비교하기 어렵다. AI에서도 사용할 도구와 자료, 생각하는 시간은 결과에 영향을 준다. 이 비유는 시험 조건을 설명하기 위한 것이며 특정 회사가 부정한 비교를 했다는 주장은 아니다.

독자가 실제 작업에서 확인할 수 있는 것은 더 구체적이다. 같은 파일과 같은 요청을 주고 제대로 끝냈는지, 원하지 않은 부분을 바꾸지 않았는지, 수정 이유를 이해할 수 있게 설명했는지를 비교한다. 단 한 번 잘됐다는 결과보다 여러 번의 일관된 성공이 내 작업에 대한 판단 근거가 된다.

문서 작업에서는 길고 그럴듯한 답보다 원문과의 일치가 중요하다. 자료에 없는 수치나 인용을 덧붙이지 않았는지, 서로 다른 날짜의 정보를 섞지 않았는지를 볼 수 있다. 문서 만들기 능력의 개선은 글의 모양만이 아니라 정보를 정리하고 근거를 유지하는 품질과 함께 평가해야 한다.

코딩에서는 검사 자체가 충분한지도 남는다. AI가 만든 시험이 특정 조건만 확인한다면 다른 상황의 오류는 놓칠 수 있다. 예를 들어 정상 주문만 시험하고 주문 취소나 빈 입력을 보지 않았다면 통과 표시가 있어도 모든 기능이 검증된 것은 아니다. 무엇을 확인했는지 구체적으로 남기는 설명이 필요한 이유다.

회사도 안전장치 개선을 강조하지만, 그 말이 사람의 승인과 권한 구분을 대신하지는 않는다. 파일을 읽는 일과 지우는 일, 수정안을 만드는 일과 실제 서비스에 반영하는 일은 영향이 다르다. AI가 오래 혼자 일할수록 어느 행동까지 맡겼는지를 분명히 하는 편이 작업 결과를 관리하기 쉽다.

이전 그록의 평가를 두고 아쉬움이 있었다면 이번에는 실제로 무엇이 달라졌는지를 볼 차례다. 미래 버전이 최고가 될 것이라는 기대와 지금 출시한 모델의 제공 조건은 분리할 수 있다. 이번 기사는 다음 버전의 약속보다 그록 4.7의 실제 출시와 회사가 공개한 개선 방향을 다뤘다.

실용적인 선택 기준은 단순하다. 내 작업을 충분히 정확하게 끝내는지, 얼마나 오래 기다리는지, 총사용료가 얼마인지다. 어려운 일에는 더 강한 다른 모델이 맞을 수 있고, 반복하는 코딩·문서 작업에서는 이번 모델이 비교할 선택지가 될 수 있다. 모든 일을 한 모델에 몰아줄 필요는 없다.

그록 4.7은 기본 가격을 유지한 채 더 긴 코딩과 업무를 맡기려는 업데이트다. 회사가 강조한 스스로 검사하는 능력과 실제 사용자의 결과 검토를 함께 보면 의미가 분명해진다. 경쟁의 승패를 한 줄로 정하기보다 같은 돈으로 원하는 작업을 얼마나 제대로 끝내는지를 살펴볼 출시다.
