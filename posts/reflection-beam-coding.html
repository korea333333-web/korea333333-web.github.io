리플렉션, 계산량 줄인 코딩 AI ‘빔’ 발표…모델 파일도 이달 공개 예고

AI 기업 리플렉션이 계산량을 줄인 코딩 AI ‘빔(Beam)’을 발표했다. 지금은 먼저 써 볼 사람을 모집한다. 리플렉션 발표

코딩 AI를 고를 때는 제대로 고치는 능력과 함께 비용과 시간을 보게 된다. 한 번에 일을 끝내면 편하지만, 틀린 부분을 계속 다시 고쳐야 한다면 사람이 쓰는 시간도 늘어난다. 계산을 아끼면서 필요한 일을 잘하는 모델이 반가운 이유다.

필요한 부분만 골라 계산한다

빔은 약 5,010억 개의 파라미터 가운데, 답변 한 조각을 만들 때 약 230억 개만 계산에 쓴다. 파라미터는 AI가 학습하며 조정한 숫자로, 답을 만드는 지식과 규칙을 담는다.

이처럼 질문마다 모델 안의 일부를 골라 계산하는 방법을 전문가 혼합, 영어로 MoE라고 부른다. 예를 들어 여러 부서를 둔 회사가 일이 들어올 때마다 필요한 부서만 부르는 모습을 떠올리면 쉽다. 실제 AI에서는 내부 계산을 여러 묶음으로 나누고, 입력에 맞는 묶음을 골라 결과를 합친다. 전문가 혼합 구조를 설명한 연구 논문

계산에 참여하는 부분을 줄여도 전체 모델 파일은 보관해야 한다. 그래서 서버의 저장 공간과 메모리는 전체 크기를 감당해야 한다. 파일 전체를 보관하면서, 답을 만들 때 계산하는 부분만 줄인다.

추정 계산량과 이용요금은 다르다

리플렉션은 고난도 시험에서 빔이 GLM 5.2와 비슷한 성능으로 3~4배 적게 계산했다고 밝혔다. 계산에 쓰는 부분과 답변 길이로 추정했다. 자료 읽기와 서버 운영 등은 제외한 값이다. 실제 이용료는 서비스 요금표로 결정된다.

계산을 적게 하는 모델이 주어진 일을 충분히 잘하면, 운영자는 같은 장비로 더 많은 요청을 처리할 여지가 생긴다. 반대로 오류 때문에 사람이 다시 고치는 시간이 길어지면 계산을 아낀 효과가 줄어든다. 코딩 도구를 고를 때는 모델 요금과 함께 수정에 걸리는 시간을 보는 것이 실용적이다.

프로그램 수정 시험 점수

이 시험에서는 AI에게 기존 프로그램과 고쳐야 할 문제를 준다. AI가 수정한 프로그램을 실행해 문제가 해결됐는지 검사한다. 짧은 코드를 써 달라는 질문보다, 여러 파일을 읽고 기존 기능을 유지하면서 고치는 실제 개발 업무에 가깝다. SWE-Bench Pro의 공식 시험 설명

실무에서는 시험에 없던 조건도 만나게 된다. 예를 들어 결제 화면을 고칠 때는 버튼이 작동하는지뿐 아니라, 잘못된 금액을 결제하거나 기존 주문 기록을 망가뜨리지 않는지도 중요하다. 모델 비교 점수와 별도로 자기 프로그램의 테스트를 돌려 확인하는 이유다.

지금은 신청 단계, 모델 파일은 이달 공개 예정

모델 파일을 내려받아 직접 실행할 수 있게 공개하는 것을 ‘공개 가중치’라고 부른다. 가중치는 앞에서 설명한, AI가 학습하며 조정한 숫자를 담은 파일이다. 파일을 직접 운영하면 모델을 제공하는 회사의 서비스 외에 다른 실행 환경을 고를 수 있다.

리플렉션은 빔의 가중치와 개발 자료를 10월 중 Apache 2.0 조건으로 공개할 계획이다. 이 조건은 자료를 사용하고 수정하거나 다시 배포할 수 있도록 허용하며, 재배포 때는 라이선스 사본과 필요한 저작권 표시 등을 남기도록 정한다. 실제 공개 파일에 붙은 조건을 기준으로 사용하면 된다. Apache 2.0 이용 조건

현재 리플렉션 API는 신청자를 순차적으로 받는 시험 서비스다. API는 다른 프로그램이 AI에게 질문하고 답을 받도록 연결하는 통로다. 개발자 안내에는 기존 OpenAI용 프로그램에서 접속 주소와 인증키를 바꿔 연결하는 방법도 설명돼 있다. 일부 기능과 한도는 시험 기간에 달라질 수 있다. 리플렉션 개발자 안내

개발자에게 실용적인 기준은 자기 프로그램을 제대로 고치면서 운영비와 수정 시간을 줄이는 모델이다. 같은 작업을 맡겨 보고, 결과를 사람이 다시 고치는 데 걸린 시간까지 비교하면 판단이 쉬워진다.

자료 안내

리플렉션 발표일은 2026년 10월 5일이다. 이 기사는 10월 6일 확인한 자료로 썼다. 대표 그림은 자체 제작 AI 콘셉트 이미지이며, 본문 그래프도 직접 제작했다.

대표 그림은 AI로 직접 만든 설명 그림이다. 한국어 문구는 그림과 분리해 배치했다. 본문 도식·그래프는 연결한 원문에 근거해 직접 제작했다.
