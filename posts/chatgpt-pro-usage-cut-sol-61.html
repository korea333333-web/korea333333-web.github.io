챗GPT Pro 사용량 너프…월 200달러 그대로, 500달러 요금제 추가

오픈AI가 월 200달러 챗GPT Pro의 기본 사용량을 줄이고, 월 500달러 상위 요금제를 추가했다. 같은 돈으로 쓸 수 있는 양이 줄어드는 ‘너프’다. 유예 조건을 충족하고 구독을 유지하는 기존 가입자는 2026년 10월 29일까지 이전 한도를 쓸 수 있다. 그 뒤에는 줄어든 한도가 적용된다.

같은 돈을 내는데 쓸 수 있는 양이 줄어든다

여기서 너프는 기존에 받던 혜택을 줄인다는 뜻이다. 이번에 줄어드는 것은 Pro에 기본으로 포함된 AI 사용량이다. 공식 Pro 안내는 새 Pro 200 가입자의 사용량을 이전보다 줄였고, 기존 가입자도 유예 기간 뒤 새 한도로 옮긴다고 명시했다.

예를 들어 매주 AI로 자료를 조사하고 글을 쓰면서 기존 한도를 거의 다 쓰던 사람이 있다. 한도가 줄면 작업 도중에 더 일찍 막힐 수 있다. 같은 돈을 내면서 하던 일을 줄이거나, 기다리거나, 추가로 결제해야 하는 상황이 생기는 것이다.

오픈AI는 모델의 효율이 높아졌다는 점을 변경 이유로 들었다. 그러나 이용자에게 중요한 것은 한 달 동안 실제로 얼마나 쓸 수 있느냐다. 성능이 좋아진 점과 구독 혜택을 줄인 결정은 따로 봐야 한다.

10월 1일 확인한 공개 안내에는 정확한 감소 폭이 없다. 개인별 변경 내용은 대상자에게 이메일로 안내한다고 밝혔다.

500달러를 내면 무엇이 추가되나

9월 29일 변경 기록에 따르면 Pro 500은 세 Pro 요금제 중 기본 사용량이 가장 많다. 아스트라가 답변을 더 빠르게 만드는 초고속 모드도 제공한다. 이 기능의 이름은 Ultrafast다. 처음에는 챗GPT 웹에서 가입할 수 있도록 안내했다.

200달러에서 500달러로 바꾸면 매달 300달러를 더 내며, 구독료는 2.5배가 된다. 한국 원화 청구액은 실제 결제 화면에서 확인해야 한다. 이 글의 금액은 미국 달러 기준이다.

다만 Pro 500의 사용량이 Pro 200의 정확히 몇 배인지는 공개 안내에 없다. 2.5배는 구독료 차이다. 사용할 수 있는 양까지 2.5배라고 계산할 수는 없다.

Pro 100·200에서 추가 사용량을 구매해도 출시 당시에는 Ultrafast를 쓸 수 없다. 이 초고속 모드를 원하면 Pro 500이 필요하다. 사용량을 더 사는 것과 상위 요금제로 바꾸는 것은 제공 기능부터 다르다.

빠르게 끝내는 모드에는 사용량도 더 든다

공식 속도 안내에서 Astra Ultrafast는 Work·Codex의 빠른 답변 생성 옵션이다. 같은 아스트라의 표준 모드와 비교하면, 구독에 포함된 사용량은 8배 비율로 차감한다. 별도로 구매한 크레딧은 6배 비율로 계산한다. 크레딧은 기본 한도를 다 쓴 뒤 추가 작업에 쓰는 유료 이용량이다.

예를 들어 표준 모드에서 사용량 1을 쓰는 만큼의 처리를 하면, Ultrafast에서는 8을 차감하는 식이다. 이는 속도 모드에 따른 차감 비율이다. 이번 Pro 기본 한도가 얼마나 줄었는지를 나타내는 숫자는 별도로 공개되지 않았다.

오픈AI가 말하는 최대 8배 속도는 AI가 답변을 만드는 속도다. 파일을 내려받거나 도구가 실행되는 시간은 따로 걸린다. 마감이 급할 때는 도움이 될 수 있지만, 반복해서 쓰면 한도도 더 빨리 소진한다.

그럼 GPT-6.1 Sol을 주로 써도 될까

오픈AI의 성능 시험을 보면, 문서와 코딩 작업에서 먼저 시도할 만하다. 실제 프로그램을 고치는 DeepSWE v1.1 평가에서 Sol 6.1은 아스트라와 같은 수준에 도달했다. 회사가 발표한 시험 결과이며, 모든 업무에서 성능이 같다는 검증은 아직 없다.

표·그림이 섞인 PDF를 읽는 평가에서도 아스트라에 가까운 성과를 냈다고 밝혔다. 기존 GPT-6 Sol보다 여러 업무 단계를 이어 수행하는 점수는 4.8%포인트 올랐다. 예를 들어 60점에서 64.8점이 되면 4.8%포인트 상승이다. 이 숫자 예시는 단위를 설명하기 위한 것이다.

내 작업에서는 같은 요청으로 비교하면 된다

블로그 운영이라면 기사 초안, 제목 수정, 홈페이지의 작은 오류 고치기부터 Sol 6.1에 맡겨 볼 수 있다. 같은 자료와 지시를 아스트라에도 주고, 틀린 숫자나 빠진 조건, 다시 고친 횟수를 비교하는 방법이다. 이 순서는 편집부의 활용 제안이다.

예를 들어 “이 세 자료에서 발표 날짜·가격·한국 이용 가능 여부를 뽑고 근거 링크를 붙여줘”라고 두 모델에 똑같이 요청한다. Sol이 한 번에 정확히 끝낸다면 그 종류의 작업은 Sol에 맡길 수 있다. 자료를 여러 번 잘못 연결하거나 중요한 조건을 빠뜨리면 아스트라로 다시 검토한다.

짧은 답이 빨리 나오는지만 보면 실제 수고를 놓치기 쉽다. 처음 답변은 빨라도 사람이 세 번 다시 고쳐야 하면 끝나는 시간은 더 길어진다. 마지막 결과까지 걸린 시간과 수정 횟수를 함께 보면 나에게 맞는 모델이 드러난다.

어려운 과학 연구처럼 최고 수준의 추론이 필요한 일은 아스트라를 남겨 둘 이유가 있다. 일상적인 초안과 반복 수정은 Sol에, 계속 막히는 문제는 아스트라에 맡기는 방식으로 나눠 볼 수 있다. 실제 한국어 글쓰기 품질은 내 자료와 문체 기준으로 확인해야 한다.

“가격이 5분의 1”과 “다섯 배 더 사용”은 다르다

Sol 6.1의 표준 API 입력·출력 단가는 아스트라의 5분의 1이다. 여기서 API는 개발자가 자기 프로그램에서 AI를 불러 쓰는 통로다. 모델 발표문의 이 가격은 챗GPT 월 구독료와 따로 계산한다.

Work·Codex 요금 안내는 실제 사용량이 모델, 자료 크기, 작업 복잡도, 도구 사용 등에 따라 달라진다고 설명한다. 그래서 Sol을 골랐을 때 구독 한도로 일을 정확히 몇 배 더 할 수 있는지는 API 가격만으로 계산할 수 없다.

작업을 바꿔 가며 남은 한도를 보면 차이를 파악하는 데 도움이 된다. 비교할 때는 새 대화에 같은 파일과 같은 지시를 넣고, 가능한 한 같은 설정을 사용한다. 아주 짧은 작업 한 번의 차이보다는 평소 하던 작업 여러 건을 끝냈을 때의 결과를 보는 편이 낫다.

모델을 바꾸면 한도가 새로 생기나

공식 모델 안내에 따르면 일반 Chat의 GPT-6 Pro 한도와 Work·Codex의 한도는 별개다. Work는 문서나 파일을 만드는 업무 기능이고, Codex는 프로그램을 만들고 고치는 도구다. Work와 Codex끼리는 사용량을 공유한다.

Work·Codex에서 Sol로 바꾸면 다른 모델로 작업하게 된다. 같은 사용량 통장에서 모델을 바꿔 쓰는 방식이므로, 이미 소진한 공동 한도가 다시 채워지지는 않는다. 한도가 남아 있을 때 어떤 모델에 어떤 일을 맡길지 나누는 것이 핵심이다.

Sol 6.1은 출시 안내 기준 Work·Codex에서 제공하며 일반 Chat에는 아직 제공하지 않는다. 계정별 적용은 순차적으로 진행된다. 일반 채팅의 Pro 한도를 다 썼다고 그 자리에 Sol 6.1이 바로 나타난다고 기대하면 혼동할 수 있다.

Sol이 좋아졌어도 Pro 사용량 너프는 남는다

Sol 6.1은 문서·코딩 작업의 현실적인 대안 후보가 됐다. 같은 일을 정확하게 끝낸다면 아스트라에 모든 작업을 맡길 필요가 줄어든다. 그 점은 직접 시험해 볼 가치가 있다.

기존 Pro 200의 기본 사용량을 줄인 결정은 이용자에게 불리하다. 200달러를 내며 하던 일을 계속하려는 사람에게는 새 한도가 충분한지가 중요하다. 새 한도가 부족한 사람은 작업량을 줄이거나 추가 비용을 부담해야 한다.
