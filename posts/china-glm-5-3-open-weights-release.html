중국 Z.ai, 보안 검토로 약 2주 늦춘 756GB AI 모델 파일 공개

중국 AI 기업 Z.ai가 8월 28일 GLM-5.3의 756GB 모델 파일을 공개했다. Z.ai는 이 모델의 해킹 관련 능력이 예상보다 빠르게 커져, 안전성 평가와 보강을 하느라 파일 공개를 약 2주 늦췄다고 설명했다. 이제 충분한 장비가 있는 기업과 연구소는 인터넷으로 AI를 빌려 쓰는 데서 그치지 않고 자기 서버에 직접 내려받아 시험할 수 있다.

이제 AI를 빌려 쓰는 대신 직접 보관할 수 있다

가장 쉬운 예는 회사의 비공개 소스 코드다. 공개 가중치가 나오기 전 일반 사용자는 Z.ai나 제휴사가 운영하는 API·호스팅 서비스에 의존해야 했다. 이제 서버를 갖춘 기업은 모델을 회사 안으로 가져와, 밖으로 보내기 어려운 코드와 문서를 내부에서 분석하는 방법을 검토할 수 있다.

GLM-5.3은 중국 즈푸AI가 해외에서 쓰는 이름인 Z.ai가 만든 초대형 업무용 AI다. 일반 챗봇처럼 질문에도 답하지만, 특히 많은 파일을 읽고 오류를 찾은 뒤 코드를 고치고 시험하는 긴 작업을 겨냥했다. 여러 단계를 스스로 이어서 처리하는 이런 프로그램을 보통 ‘AI 에이전트’라고 부른다.

모델 파일이 공개되기 전에도 GLM-5.3을 쓸 수는 있었다. 다만 사용자는 인터넷을 통해 질문을 보내고 답을 받는 API 방식에 의존해야 했다. API는 식당에서 음식을 주문하는 창구와 비슷하다. 요리는 업체 주방에서 하고, 사용자는 결과만 받는다.

이번에는 주방의 핵심 재료에 해당하는 공식 모델 파일이 공개됐다. 충분한 장비가 있다면 기업과 연구소가 파일을 직접 보관하고 자기 서버에서 실행할 수 있다. 서비스 업체가 가격이나 사용량 한도를 바꾸더라도, 이미 내려받은 같은 버전을 계속 시험할 수 있다는 뜻이다.

물론 무료 파일을 받았다고 운영비까지 사라지는 것은 아니다. 초대형 모델을 돌릴 서버와 전력, 관리 인력이 필요하고 라이선스 조건도 지켜야 한다. 이번 공개로 바뀐 것은 ‘누가 모델을 보관하고 통제하느냐’이지, 거대한 AI가 갑자기 개인용 컴퓨터에서도 가볍게 돌아가게 됐다는 뜻은 아니다.

날짜를 나눠 보면 사건이 더 분명하다. Z.ai는 8월 14일 GLM-5.3을 처음 발표했다. 이어 8월 19일에는 인터넷 API의 정식 제공을 발표했지만, 모델 파일은 바로 내놓지 않았다.

Z.ai는 안전성 평가와 보강을 거친 뒤 약 2주 후 파일을 공개하겠다고 밝혔다. 실제 가중치 파일이 Hugging Face에 올라온 날은 한국 시간 8월 28일이다. 따라서 8월 14일은 모델 발표, 8월 19일은 API 정식 제공 발표, 8월 28일은 다운로드 가능한 파일 공개로 구분해 읽어야 한다.

756GB는 저장 크기이지 실행 장비의 크기가 아니다

이번에 공개된 대용량 모델 파일의 핵심은 ‘가중치’다. 가중치는 AI가 학습하면서 만든 수많은 숫자의 묶음이다. 질문에서 무엇을 중요하게 보고 어떤 단어를 이어 답할지 정하는, AI의 기억과 판단 규칙이라고 이해하면 된다.

Hugging Face는 GLM-5.3 저장소 전체 크기를 756GB로 표시한다. 숫자만 보면 1TB 저장장치에 넣을 수 있으니 일반 컴퓨터에서도 돌아갈 것처럼 보인다. 하지만 756GB는 파일을 보관하는 데 필요한 공간일 뿐, 실제 실행에 필요한 장비의 크기가 아니다.

비유하면 저장장치는 상자를 쌓아 두는 창고이고, AI를 실행하는 고속 메모리와 계산 장치는 상자를 펼쳐 동시에 작업하는 넓은 작업대다. 창고가 충분해도 작업대가 작으면 일을 시작할 수 없다. GLM-5.3은 여러 고성능 계산 장치와 큰 메모리가 필요한 서버용 모델이지, 노트북에 받아 바로 쓰는 프로그램이 아니다.

공개된 파일 가운데 실제 가중치는 정확히 141개 조각으로 나뉘어 있다. 첫 파일 이름도 model-00001-of-00141.safetensors다. 여기서 141은 작은 AI가 141개 들어 있다는 뜻이 아니다. 너무 큰 AI 하나를 내려받고 여러 계산 장치에 나눠 올리기 쉽게 쪼갠 것이다.

따라서 조각 하나만 골라 받아 작은 모델처럼 사용할 수는 없다. GLM-5.3 전체를 실행하려면 시스템이 141개 가중치 조각을 모두 읽을 수 있어야 한다. 파일을 나눈 것은 운반과 배치를 쉽게 하려는 방법이지, 모델 자체를 141개 제품으로 나눈 것이 아니다.

Hugging Face가 공개 파일을 바탕으로 표시한 모델 규모는 753B다. 한국식으로 쓰면 약 7,530억 개의 파라미터다. 파라미터는 가중치를 이루는 각각의 숫자다. 숫자가 많을수록 더 많은 관계와 패턴을 담을 여지는 있지만, 덩치가 크다고 모든 질문에서 자동으로 더 정확한 것은 아니다.

공식 설정 파일에는 FP8 방식이 적혀 있다. FP8은 일부 숫자를 더 작은 칸에 담아 저장 공간과 계산 부담을 줄이는 방법이다. 그래서 이번 파일을 학습 때의 모든 정밀도를 그대로 담은 ‘원본’이라고 부르면 부정확하다. Z.ai가 공식 배포한 실행용 가중치라고 하는 편이 맞다.

가중치가 공개됐다고 학습에 쓴 자료와 만드는 과정까지 모두 공개된 것도 아니다. 누구나 처음부터 똑같은 모델을 다시 만들 수 있다는 뜻은 아니다. 가장 정확한 표현은 ‘완전한 오픈소스’보다 ‘가중치를 내려받아 실행하고 수정하고 검증할 수 있는 오픈웨이트 모델’이다.

그래도 외부에서 확인할 수 있는 범위는 크게 넓어졌다. 연구자는 같은 질문을 반복해 답이 얼마나 흔들리는지 볼 수 있고, 기업은 한국어 문서와 자체 코드를 넣어 실제 오류율을 잴 수 있다. 라이선스 범위 안에서는 저장 크기를 더 줄인 버전이나 특정 업무에 맞춘 수정판도 만들 수 있다.

파일을 늦춘 이유는 사이버 보안 능력이었다

GLM-5.3은 완전히 새 밑바탕에서 만든 모델이 아니다. Z.ai 설명에 따르면 이전 GLM-5.2와 같은 기초 모델을 사용한 뒤, 코딩과 긴 작업, 사이버 보안 문제를 더 많이 연습시킨 버전이다. 사람으로 치면 같은 기본 교육을 받은 뒤 보안 훈련을 추가한 셈이다.

그 과정에서 취약점을 찾고 여러 공격 단계를 이어 붙이는 능력이 회사 예상보다 빠르게 커졌다고 Z.ai는 설명했다. 그래서 인터넷 API는 먼저 열되, 사용자가 통제할 수 있는 모델 파일은 바로 배포하지 않고 안전성을 더 살폈다. Axios도 이 약 2주의 공개 연기를 별도로 보도했다.

API와 다운로드 파일의 차이는 통제권에 있다. API로만 쓸 때는 Z.ai가 위험한 요청을 감지해 막거나 계정을 정지할 수 있다. 하지만 누군가 파일을 받아 자기 서버에서 돌리면 Z.ai가 그 복사본을 멀리서 끌 수 없다. 공개 전에 더 조심해야 했던 이유다.

여기서 ‘해킹 능력이 커졌다’는 말을 실제 기업을 마음대로 뚫었다는 뜻으로 받아들이면 안 된다. Z.ai가 공개한 수치는 정해진 코드와 취약점을 통제된 시험 환경에서 풀게 한 결과다. 회사 평가에서 CyberGym 점수는 77.2에서 84.5로, ExploitBench는 24.4에서 54.4로 올랐다.

두 수치는 모두 Z.ai가 발표한 회사 측 결과다. 다른 연구기관이 같은 조건으로 반복해 같은 점수를 얻었다는 독립 확인은 아직 충분하지 않다. 특히 ExploitBench 숫자가 크게 올랐다고 해서 현실의 모든 해킹 성공률이 두 배가 됐다고 해석할 수는 없다.

Artificial Analysis의 독립 API 평가에서는 GLM-5.3의 종합지수가 60으로 집계됐다. 답변은 평균보다 길고 출력 속도는 다소 느린 편으로 평가됐다. 다만 이것은 전반적인 추론 능력을 비교한 시험이지, Z.ai가 공개한 두 사이버 보안 점수를 다시 확인한 시험은 아니다.

보안 능력은 공격과 방어에 모두 쓰인다. 나쁜 목적을 가진 사람은 결함을 더 빨리 찾는 데 이용할 수 있고, 소프트웨어 관리자는 사람이 놓친 약점을 먼저 찾아 고칠 수 있다. 같은 도구라도 누가 어떤 권한을 주고 어디에서 실행하느냐에 따라 위험이 달라진다.

따라서 지금 확실히 말할 수 있는 것은 ‘세계 최고의 해킹 AI가 풀렸다’가 아니다. 회사 설명만 읽던 단계에서 벗어나, 외부 연구자가 같은 파일을 받아 성능과 위험을 직접 확인할 수 있게 됐다는 점이다.

앞으로는 위험한 요청을 제대로 거절하는지, 표현을 살짝 바꾸면 안전장치를 우회하는지, 취약점을 찾은 뒤 실제 공격 명령까지 만드는지를 차례로 시험해야 한다. 공개 직후에는 이런 독립 결과가 충분히 쌓이지 않았으므로 섣부른 결론을 내리기 이르다.

MIT 라이선스가 아니며 대형 모델 서비스에는 별도 조건이 붙는다

파일을 무료로 받을 수 있다고 아무 조건 없이 써도 되는 것은 아니다. GLM-5.3은 이전 버전에서 쓰던 MIT가 아니라 별도의 GLM-5.3 라이선스를 적용한다.

기본 범위는 비교적 넓다. 사용하고 복사하고 수정하고 배포하거나 판매하는 일을 일반적으로 허용한다. 대신 저작권과 라이선스 문구를 남기고, 적용되는 법률을 지켜야 한다.

추가 조건은 아주 큰 모델 서비스 사업자를 겨냥한다. 여기서 모델 서비스(MaaS)는 외부 고객에게 모델 추론이나 미세조정을 제공하면서, 고객이 입력·설정 등에 실질적인 통제권을 갖는 서비스를 뜻한다. 회사와 관계사의 합산 매출이 연속 12개월 기준으로 100억 달러를 넘으면 상업적으로 사용하기 전에 Z.ai의 보안 검토를 통과해야 한다.

두 조건은 함께 충족돼야 한다. 단순히 매출이 큰 제조업체라는 이유만으로 자동 적용되는 조항은 아니다. 반대로 대형 클라우드나 모델 API 회사라면 기술 시험을 시작하기 전에 법무·보안팀이 해당 여부를 확인해야 한다.

예외도 있다. 모델이 특정 기능 안에만 들어간 최종 사용자 제품은 라이선스가 말하는 MaaS에서 제외된다. 다른 업체가 운영하는 모델에 요청을 그대로 전달하기만 하는 서비스도 제외된다.

따라서 개인 개발자와 대부분의 일반 기업이 아예 쓸 수 없다는 뜻은 아니다. 다만 MIT처럼 저작권 문구만 지키면 거의 끝나는 조건도 아니다. 특히 거대한 모델을 다른 고객에게 서비스하려는 회사는 사업 형태와 매출 기준을 함께 살펴야 한다.

한국 기업은 내부망 시험부터 시작할 수 있다

한국 기업이 얻은 가장 현실적인 선택지는 내부망 시험이다. 충분한 서버가 있다면 민감한 소스 코드와 사내 문서를 외부 API로 보내지 않고, 회사 안에서 코드 검토와 긴 문서 분석, 보안 취약점 찾기를 시험할 수 있다.

대학과 보안 연구기관도 Z.ai의 허락을 기다리지 않고 같은 파일을 반복 평가할 수 있다. 회사가 발표한 점수가 실제로 재현되는지, 한국어 문서와 국내 개발 환경에서도 비슷한 성능이 나오는지 직접 확인할 길이 열린 것이다.

처음부터 큰 업무를 맡길 필요는 없다. 정답을 알고 있는 코드 오류와 계약서 질문을 각각 수십 개 준비한 뒤, 답이 맞는지와 얼마나 빨리 나오는지, 사람이 얼마나 고쳐야 하는지, 서버 비용이 얼마인지를 함께 재는 편이 좋다.

공개 성능표만 보고 도입을 결정하면 안 된다. 중국어와 영어 시험 점수가 높아도 한국어 숫자 단위와 높임말, 국내 법률 문서를 정확히 처리한다는 보장은 없다. 회사가 실제로 하는 일과 비슷한 자료로 시험해야 비용 대비 효과를 알 수 있다.

권한은 아주 좁게 시작해야 한다. 처음부터 외부 인터넷과 실제 서버 명령, 비밀키, 고객 데이터에 접근하도록 열어 주면 안 된다. 읽기 전용 코드와 격리된 시험 환경에서 먼저 돌리고, 모델이 찾았다는 취약점은 사람이 다시 확인한 뒤 정식 신고 절차를 따라야 한다.

공개 저장소의 파일과 설명은 나중에 바뀔 수 있다. 시험 기록에는 모델 이름뿐 아니라 내려받은 날짜와 커밋 번호, 파일 해시를 함께 남기는 편이 안전하다. 해시는 파일마다 달라지는 디지털 지문이다. 이 기록이 있어야 결과가 달라졌을 때 모델 파일이 바뀐 것인지 실행 환경이 바뀐 것인지 구분할 수 있다.

아직 모르는 점: Z.ai가 2주 동안 정확히 무엇을 고쳤는지, 공개 파일이 기존 인터넷 API에서 쓰던 모델과 완전히 같은지, 다른 연구기관도 회사가 발표한 사이버 보안 점수를 다시 얻을 수 있는지는 충분히 확인되지 않았다. 파일을 공개했다는 사실이 곧 안전하다는 뜻은 아니다.

GLM-5.3 공개의 핵심은 ‘중국 해킹 AI가 풀렸다’는 자극적인 문장이 아니다. 회사 서버 안에 있던 거대한 AI가 실제로 내려받을 수 있는 파일이 됐다는 점이다. 이제 기업은 내부에서 써 볼 수 있고 연구자는 회사 발표를 직접 확인할 수 있다. 그만큼 사용자가 장비와 보안, 라이선스 책임까지 함께 떠안게 됐다.
