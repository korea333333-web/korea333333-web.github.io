메타, 이전 대화를 기억하고 긴 일을 이어가는 AI 공개

메타가 이전 대화의 중요한 내용을 찾아 쓰고, 여러 단계의 일을 이어가는 새 AI ‘뮤즈 원더(Muse Wonder)’를 10월 12일 공개했다. 개발자용 연결 서비스와 코딩 도구에서 이용할 수 있으며, 공식 개발 문서는 현재 시험 제공 단계로 안내한다.

메타는 이전 대화에서 필요한 정보를 찾는 기능을 Active Memory, 일이 막혀도 다른 방법을 시도하는 기능을 Active Focus라고 설명했다. 중요한 행동 전에는 사용자에게 확인하는 설계다. 메타의 제품 발표에 담긴 설명이며, 실제 업무에서의 성공률은 별도 시험이 필요하다.

기억을 잘하는 것과 일을 끝내는 것은 다르다

예를 들어 매주 강의 자료를 만든다면 “지난번처럼 초보자에게 쉽게 설명하고, 이번에는 실습을 하나 더 넣어 달라”고 부탁하고 싶을 수 있다. 앞서 정한 독자와 문체를 매번 다시 입력하는 수고를 줄이려는 장면이다. 이는 기능의 의미를 설명하기 위한 편집부의 예시다.

이전 조건을 찾은 뒤에도 자료를 고치고 결과를 확인하는 일이 남는다. 기억은 무엇을 참고할지의 문제이고, 긴 작업의 수행은 그 자료로 무엇을 끝낼지의 문제다. 이번 발표는 이 두 가지를 함께 다룬다.

지금은 개발자와 코딩 작업부터 제공한다

현재 접근 방법은 크게 두 가지다. 개발자가 자신의 프로그램에서 AI를 호출하려면 Meta Model API를 쓰고, 준비된 코딩 도구로 작업하려면 Muse Code를 쓴다. API는 프로그램끼리 요청과 답을 주고받는 연결 통로다. 일반 이용자가 대화창을 여는 것과는 준비 과정이 다르다.

공식 개발자 안내는 뮤즈 원더가 여러 파일을 고치고, 일을 나누어 처리하며, 복잡한 소프트웨어 작업을 이어가도록 설계됐다고 설명한다. 기존 뮤즈 스파크용 요청 형식을 활용할 수 있다는 점도 안내한다. 이미 메타의 개발 도구를 쓰는 사람에게는 새 모델을 시험할 수 있는 경로가 생긴 셈이다.

뮤즈 코드는 실제 프로젝트의 파일을 편집하고 명령을 실행하는 도구다. 제품 안내에 따르면 처음부터 작업 승인과 실행 범위를 제한하는 보호 기능이 켜진다. 윈도·맥·리눅스에서 실행할 수 있지만, 윈도에서는 음성 입력과 실행 중인 작업 사이의 메시지 교환을 지원하지 않는 등 차이가 있다.

이 차이는 도입할 때 확인할 부분이다. 예를 들어 코딩을 맡긴다면 AI의 설명만 읽는 데서 끝내지 않고, 어떤 파일을 바꾸고 어떤 명령을 실행했는지 살펴보는 편이 좋다. 문서 초안과 프로그램 수정은 검토 대상이 다르기 때문이다.

AI가 기억하는 범위와 실행할 권한을 나눠 본다

AI에게 일을 맡긴다는 말에는 두 단계가 섞여 있다. 자료를 읽어 수정안을 제시하는 일과, 원본 파일을 실제로 바꾸는 일이다. 예를 들어 홈페이지의 안내문을 고친다면 “바꿀 문장을 먼저 보여 줘”와 “사이트의 파일을 수정해 줘”는 결과가 다르다. 처음 시험할 때는 어느 단계까지 원하는지 분명히 적는 편이 좋다.

뮤즈 코드의 권한 안내는 실행 전 승인과 컴퓨터가 강제하는 작업 범위 제한을 구분한다. 승인은 해당 행동을 진행해도 되는지 판단하는 절차다. 작업 범위 제한은 프로그램이 쓸 수 있는 파일 위치와 접속할 수 있는 네트워크를 정한다. 허락을 묻는 창과 컴퓨터의 접근 제한은 서로 다른 장치다.

안내에는 파일을 읽되 바꾸지 않는 Read-only 설정도 있다. 기본 Auto-review에서는 승인 대상 행동을 자동 검토자가 판단하며, Ask me에서는 사용자에게 물어본다. 따라서 모든 행동 앞에서 같은 확인창이 뜨는 것으로 생각하기보다 현재 권한 설정을 보고 맡길 범위를 정하는 것이 정확하다.

가상의 홈페이지 수정 작업이라면 먼저 복사본에서 문구만 고치게 하고, 연락처·날짜가 그대로인지 비교할 수 있다. 기억한 조건이 정확했는지와 실행 결과가 올바른지를 따로 보는 시험이다. 이처럼 작은 결과물을 기준으로 확인하면 “AI가 오래 일했다”보다 무엇을 잘했는지가 분명해진다.

API는 사용량 요금, 상위 모델은 구독 조건이 있다

공식 모델 안내에 표시된 뮤즈 원더 API 요금은 100만 토큰 기준 입력 4달러, 출력 20달러다. 토큰은 AI가 읽고 쓰는 글을 계산할 때 나누는 작은 단위이며, 한국어 글자 수와 일치하지 않는다. 긴 요청과 답변을 반복하면 사용량이 쌓이는 방식이다.

상위 모델인 Muse Wonder Full은 Muse Code의 Power Usage와 Maximum Usage 구독에서 제공된다. 확인 시점의 월 요금은 각각 50달러와 200달러로 표시돼 있다. 실제 결제 금액과 조건은 가입 화면에서 확인할 부분이다.

일반 소비자용 Muse에는 구독자부터 순차 제공할 계획이다. 한국의 모든 계정에서 사용할 수 있는지는 이번 공개 자료로 확인되지 않았다. 발표에 나온 시연과 설계를 근거로 회사 자료를 제한 없이 맡기거나 자동 실행을 넓히기보다는, 제공된 기능과 권한을 먼저 살펴볼 단계다.

이번 소식의 중심은 AI가 앞선 대화를 다시 참고하며 일을 이어가도록 발전하고 있다는 점이다. 실제 효용은 기억을 잘 꺼내는지, 수정 결과가 맞는지, 중요한 순간에 사람의 확인을 받는지에서 드러난다.
