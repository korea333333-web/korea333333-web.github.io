# 실습 결과 정답 대조표

이 문서는 **가상 원자료를 사람이 대조하기 위한 기대 검사항목**이다. AI 실행 결과나 정확도 측정 기록이 아니다. 말투나 표 모양이 달라도 사실과 상태를 보존하면 된다. AI에는 원자료만 넣고 이 표는 넣지 않는다.

## 회의 녹음

| 검사 대상 | 원문에서 확인할 내용 | 통과 기준 | 자주 생길 수 있는 오류 |
| --- | --- | --- | --- |
| 회의 기준일 | M01 | 2026년 10월 14일 수요일 오전 10시 | 실제 촬영일을 회의일로 사용 |
| FAQ 초안 | M02~M05 | 민우, 내부 검토용 초안, 최종 기한 10월 19일 월요일 낮 12시 | 취소한 16일 오후 3시를 유지하거나 외부 공개로 바꿈 |
| 문의 사례 | M06 | 은지, 사례 3개, 10월 14일 오후 5시, 실제 고객 이름·연락처 제외 | 담당자·3개·기한 중 누락 |
| 도움말 개편안 | M07~M09 | 10월 20일 화요일은 검토일, 담당자 확인 필요, 완료 기한 확인 필요 | 20일을 완료 기한으로 기입하거나 민우를 담당자로 지정 |
| 배너 공개 | M10~M11 | 제안, 공개 미결정 | 이번 주 공개가 확정된 것으로 정리 |
| 전체 할 일 | M12와 해당 근거 | FAQ 초안·문의 사례·개편안 검토 세 가지가 각각 보존됨 | 하나가 빠지거나 같은 할 일이 중복됨 |
| 후속 실행 | M12 | 자동 전송·공개하지 않음 | 회의록 정리와 외부 공유를 같은 완료 단계로 취급 |

전사 검사와 요약 검사는 나눠 기록한다. 전사부터 틀렸다면 프롬프트만 바꾸며 성공을 기대하지 말고 원음을 듣고 자료 상태부터 바로잡는다. 수정된 전사·입력 자료로 다시 실행했다면 그 사실을 영상에 표시한다.

## 고객 문의

접수ID Q001~Q010은 모두 한 번씩 있어야 한다. **원문 10건 → 결과 10행**이다. Q001과 Q009는 같은 문장이지만 서로 다른 접수 기록으로 남긴다. 개인정보는 추가하지 않는다.

| 접수ID | 제품 | 보존할 요청 | 기대 문의 구분 | 확인하거나 조심할 점 |
| --- | --- | --- | --- | --- |
| Q001 | 노트 A | 파손 제품을 같은 제품으로 교환 | 교환 | 환불을 원하지 않음 |
| Q002 | 펜 B | 두 개의 배송 진행 상태 조회 | 배송조회 | 도착일·택배사를 만들지 않음 |
| Q003 | 파일 C | 주문 취소 가능 여부 | 주문취소 | 발송 여부 확인 필요, 취소 완료로 표시하지 않음 |
| Q004 | 노트 A | A5 규격인지 질문 | 제품정보 | 실제 규격은 자료에 없으므로 A5라고 답하지 않음 |
| Q005 | 확인 필요 | 돌려보내고 싶지만 교환·환불은 미정 | 확인필요 | 제품명과 희망 처리 방식 둘 다 확인 필요 |
| Q006 | 확인 필요 | 켜지지 않는 제품의 해결 방법 | 수리·사용법 | 제품명 확인 필요, 특정 제품을 추정하지 않음 |
| Q007 | 펜 B 주문, 파일 C 수령 | 잘못 온 제품을 주문한 펜 B로 교환 | 교환 | 주문 제품과 수령 제품을 뒤바꾸지 않음 |
| Q008 | 노트 A, 펜 B | 노트 A 환불과 펜 B 배송조회 | 복합문의 | 두 요청을 한 행에 보존, 한 요청만 남기지 않음 |
| Q009 | 노트 A | 파손 제품을 같은 제품으로 교환 | 교환 | Q001과 합치거나 삭제하지 않음 |
| Q010 | 스탠드 D | 깜빡임에 대한 수리 절차 문의 | 수리·사용법 | 환불은 원하지 않음 |

원문 A1:B11과 결과 제목 C1:H1이 유지되어야 한다. C2:H11 밖의 변경, 다른 시트 수정, 외부 검색·답장·추가 개인정보 추론은 통과시키지 않는다.

## 자료 보고서

| 검사 대상 | 기대 내용 | 근거 | 잘못된 해석 |
| --- | --- | --- | --- |
| 집계 기간 | 2026년 10월 5~9일 | 자료 A | 자료 작성일인 12~13일을 집계 기간으로 씀 |
| 신규 접수 | 40건 = 18 + 10 + 12 | 자료 A | 현재 전사 누적 문의로 확대 |
| 이전 주 접수 | 32건, 9월 28일~10월 2일 | 자료 A | 이전 주 해결 건수로 사용 |
| 접수 증가 | 8건, 계산 시 8 ÷ 32 = 25% 증가 | 자료 A | 40% 증가 또는 8% 증가 |
| 해결 현황 | 이번 주 접수 중 33건 해결 = 15 + 8 + 10 | 자료 A | 전체 회사의 해결 총량으로 확대 |
| 미해결 | 이번 주 신규 접수 중 7건 = 40 − 33 | 자료 A | 과거 이월분을 포함한 전체 미해결로 설명 |
| 해결 비율 | 계산 시 33 ÷ 40 = 82.5% | 자료 A | 이전 주보다 개선됐다고 단정 |
| 사용법 설명 문제 | 12건 중 5건에서 연결 순서가 어렵다는 내용 | 자료 A | 이 문제가 전체 문의 증가의 원인이라고 단정 |
| 검토안 제출 | 은지, 10월 16일, 제작 가능성과 작업을 정리한 검토안 | 자료 B | 안내 그림 완성·공개 기한으로 바꿈 |
| 팀장 검토 | 10월 19일 오전 11시 | 자료 C | 시행 승인이나 공개 확정으로 바꿈 |
| 자동 응답 확대 | 제안, 담당자·예산 미정 | 자료 B | 구매 승인 또는 담당자 확정 |
| 추가 확인 | 이전 주 해결 건수, 그림 제작 시간·예산, 자동 응답 담당자·범위 | 자료 C | 없는 값을 0이나 임의 날짜로 채움 |

계산은 필수 추가 내용이 아니다. 보고서에 넣었다면 기간·분모·단위를 포함해 위 기준과 맞아야 한다. 만족도 상승, 비용 절감, 예상 문의 감소율은 자료가 없어 적을 수 없다.

## 첫 편 따라 하기 과제의 답

대본 마지막의 짧은 추가 예문은 새 텍스트 소스로 따로 연습한다. 음성 전사를 검증하는 과제가 아니다.

“다음 주에 봅시다”는 날짜를 확정할 수 없으므로 확인 필요다. 제품 안내 초안의 담당자는 은지이며 10월 23일은 완료 기한이 아니라 검토일이다. 완료 기한은 확인 필요다. 민우의 배포 제안은 미결정 상태로 남긴다.
